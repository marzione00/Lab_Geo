1. Preparare un criterio per le due misure richieste

Ricostruiamo conversione e controlli senza dipendere da altri quaderni. Definiamo prima le coppie finite, poi positività e ordine. Categoria e duplicazione sono controlli separati, necessari per scegliere quali record entrano nella tabella derivata.

R · codice commentato
# Conservare anche stringhe vuote e codici testuali prima di interpretarli.
raw <- carica_dati("fossili_da_controllare.csv", sep = ";",
                   colClasses = "character", na.strings = character(),
                   stringsAsFactors = FALSE)
stopifnot(nrow(raw) == 25L)

converti_misura <- function(x) {
  testo <- trimws(x)
  mancante <- is.na(testo) | toupper(testo) %in% c("", "NA", "ND")
  normalizzato <- gsub(",", ".", testo, fixed = TRUE)
  # La grammatica accetta decimali semplici; non interpreta simboli di censura.
  numerico <- !mancante & grepl("^[+-]?([0-9]+([.][0-9]*)?|[.][0-9]+)$", normalizzato)
  valore <- rep(NA_real_, length(x))
  valore[numerico] <- as.numeric(normalizzato[numerico])
  data.frame(originale = x, valore = valore, mancante = mancante,
             fallito = !mancante & !numerico, stringsAsFactors = FALSE)
}

misure <- c("diametro_tot_um", "diametro_int_um", "diaframma_um")
conversioni <- lapply(raw[misure], converti_misura)
f <- raw
for (nome in misure) f[[nome]] <- conversioni[[nome]]$valore
f$riga_origine <- seq_len(nrow(f))

finita <- is.finite(f$diametro_tot_um) & is.finite(f$diametro_int_um)
geometria_ok <- finita & f$diametro_tot_um > 0 & f$diametro_int_um > 0 &
                f$diametro_int_um <= f$diametro_tot_um
categoria_ok <- tolower(trimws(f$morfotipo)) %in% c("rounded", "spiky")
copia <- duplicated(raw)
utilizzabile <- geometria_ok & categoria_ok & !copia
stopifnot(!anyNA(utilizzabile))
print(c(record = nrow(f), coppie_finite = sum(finita), utilizzabili = sum(utilizzabile)))

Le coppie finite possono essere rappresentate nel grafico anche se geometricamente errate. Le righe con un diametro mancante non hanno coordinate complete e vengono contate separatamente, invece di sparire senza spiegazione.

2. Disegnare il vincolo geometrico

Rappresentiamo diametro esterno sull’asse orizzontale e interno su quello verticale. La retta di uguaglianza separa coppie compatibili dall’interno maggiore dell’esterno; il colore distingue le anomalie geometriche, mentre un simbolo aggiuntivo segnala la copia esatta.

R · codice commentato
colori <- ifelse(geometria_ok[finita], "steelblue", "firebrick")

     col = colori, xlab = "Diametro esterno (um)", ylab = "Diametro interno (um)")
abline(a = 0, b = 1, lty = 2)

       col = c("steelblue", "firebrick", "black"), pch = c(19, 19, 1), bty = "n")
print(f[!finita, c("id", "diametro_tot_um", "diametro_int_um")])

3. Calcolare spessore e rapporto

Le formule vengono applicate soltanto alle righe utilizzabili. Lo spessore conserva l’unità dei diametri; il rapporto è adimensionale. Manteniamo NA nelle altre righe e verifichiamo gli intervalli imposti dalle definizioni.

R · codice commentato
f$spessore_um <- NA_real_
f$rapporto_int_tot <- NA_real_
f$spessore_um[utilizzabile] <- (f$diametro_tot_um[utilizzabile] - f$diametro_int_um[utilizzabile]) / 2
f$rapporto_int_tot[utilizzabile] <- f$diametro_int_um[utilizzabile] / f$diametro_tot_um[utilizzabile]
print(head(f[utilizzabile, c("id", "spessore_um", "rapporto_int_tot")]))
stopifnot(all(f$spessore_um[utilizzabile] >= 0))
stopifnot(all(f$rapporto_int_tot[utilizzabile] > 0 & f$rapporto_int_tot[utilizzabile] <= 1))
write.csv(f, percorso_risultati("fossili_misure_derivate.csv"), row.names = FALSE)

Lettura del risultato

Dividere la differenza dei diametri per due presuppone il modello di uno spessore radiale confrontabile sulle due pareti. In forme eccentriche o irregolari questa quantità resta una misura convenzionale e non descrive necessariamente ogni spessore locale.

Variante svolta

Verificare che il diametro interno si ricostruisca da esterno e spessore.

interno_ricostruito <- f$diametro_tot_um[utilizzabile] - 2 * f$spessore_um[utilizzabile]
scarti <- interno_ricostruito - f$diametro_int_um[utilizzabile]
print(max(abs(scarti)))
stopifnot(isTRUE(all.equal(interno_ricostruito, f$diametro_int_um[utilizzabile])))
Risultato dell’esecuzione
[1] 0

La relazione inversa verifica l’implementazione della formula e gli abbinamenti. Non controlla da sola il modello geometrico del fossile: un calcolo algebricamente corretto può richiedere una diversa interpretazione per forme non concentriche.

Errore da riconoscere

Un punto lontano dagli altri non è necessariamente errato, mentre un diametro interno maggiore dell’esterno viola una definizione esplicita. Il controllo usa vincoli documentati, non la sola rarità statistica.
