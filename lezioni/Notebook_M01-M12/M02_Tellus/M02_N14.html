1. Convertire senza perdere il riferimento originale

L’esercizio ricostruisce autonomamente la conversione delle tre misure e conserva l’ordine del file. I controlli fisici si applicano ai numeri convertiti, mentre il testo rimane disponibile per distinguere problemi di rappresentazione e anomalie della misura.

R · codice commentato
# Conservare anche stringhe vuote e codici testuali prima di interpretarli.
raw <- carica_dati("fossili_da_controllare.csv", sep = ";",
                   colClasses = "character", na.strings = character(),
                   stringsAsFactors = FALSE)
stopifnot(nrow(raw) == 25L)

converti_misura <- function(x) {
  testo <- trimws(x)
  mancante <- is.na(testo) | toupper(testo) %in% c("", "NA", "ND")
  normalizzato <- gsub(",", ".", testo, fixed = TRUE)
  # La grammatica accetta decimali semplici; non interpreta simboli di censura.
  numerico <- !mancante & grepl("^[+-]?([0-9]+([.][0-9]*)?|[.][0-9]+)$", normalizzato)
  valore <- rep(NA_real_, length(x))
  valore[numerico] <- as.numeric(normalizzato[numerico])
  data.frame(originale = x, valore = valore, mancante = mancante,
             fallito = !mancante & !numerico, stringsAsFactors = FALSE)
}

misure <- c("diametro_tot_um", "diametro_int_um", "diaframma_um")
conversioni <- lapply(raw[misure], converti_misura)
f <- raw
for (nome in misure) f[[nome]] <- conversioni[[nome]]$valore
f$riga_origine <- seq_len(nrow(f))

stopifnot(!any(vapply(conversioni, function(x) any(x$fallito), logical(1))))
print(head(f, 6))

2. Definire indicatori indipendenti

La disponibilità di tutte le misure è diversa dalla loro ammissibilità geometrica. Costruiamo indicatori separati, facendo in modo che ciascuno sia sempre vero o falso, anche quando una misura manca. Aggiungiamo categoria e duplicato senza cancellare le righe.

R · codice commentato
f$completo <- rowSums(is.finite(as.matrix(f[misure]))) == length(misure)
f$nonpositivo <- rowSums(sapply(f[misure], function(x) is.finite(x) & x <= 0)) > 0
f$interno_maggiore <- is.finite(f$diametro_tot_um) & is.finite(f$diametro_int_um) &
                      f$diametro_int_um > f$diametro_tot_um
f$categoria_ok <- tolower(trimws(f$morfotipo)) %in% c("rounded", "spiky")
f$duplicato_esatto <- duplicated(raw)
flag <- f[c("completo", "nonpositivo", "interno_maggiore", "categoria_ok", "duplicato_esatto")]
stopifnot(!anyNA(flag))
print(f[!f$completo | f$nonpositivo | f$interno_maggiore | f$duplicato_esatto,
        c("id", "riga_origine", names(flag))])

Una riga può comparire in più categorie di problema. Il vincolo interno minore o uguale all’esterno usa il modello geometrico del fossile; non viene deciso sulla base della distribuzione statistica dei valori osservati.

3. Dichiarare la disponibilità per questa analisi

L’analisi proposta richiede tutti e tre i valori, positività, geometria coerente e una sola copia per record identico. La colonna utilizzabile riunisce questi requisiti, mentre i singoli indicatori spiegano perché una riga non vi rientra.

R · codice commentato
f$utilizzabile <- f$completo & !f$nonpositivo & !f$interno_maggiore &
                  f$categoria_ok & !f$duplicato_esatto
print(c(totali = nrow(f), utilizzabili = sum(f$utilizzabile),
        da_verificare = sum(!f$utilizzabile)))
motivi <- c(incompleto = sum(!f$completo), nonpositivo = sum(f$nonpositivo),
             geometria = sum(f$interno_maggiore), copia = sum(f$duplicato_esatto))
print(motivi)
write.csv(f, percorso_risultati("fossili_audit_geometrico.csv"), row.names = FALSE)
stopifnot(sum(f$utilizzabile) + sum(!f$utilizzabile) == nrow(raw))

Cambiare il requisito non significa ignorare un’anomalia: significa riconoscere che formule diverse richiedono informazioni diverse. I due denominatori devono accompagnare i rispettivi risultati per evitare confronti fra insiemi non dichiarati.

Errore da riconoscere

Applicare un unico filtro di completezza a qualunque analisi può eliminare osservazioni utilizzabili per una specifica domanda. La disponibilità va definita in relazione alle variabili effettivamente necessarie.
