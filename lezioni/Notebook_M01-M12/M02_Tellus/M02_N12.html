1. Definire la conversione prima di applicarla

La funzione conserva il testo, elimina spazi esterni e uniforma il separatore decimale. Prima di usare as.numeric verifica una grammatica di decimali semplici: una stringa non riconosciuta viene segnalata come conversione fallita, distinta da un codice mancante.

R · codice commentato
converti_misura <- function(x) {
  testo <- trimws(x)
  mancante <- is.na(testo) | toupper(testo) %in% c("", "NA", "ND")
  normalizzato <- gsub(",", ".", testo, fixed = TRUE)
  # La grammatica accetta decimali semplici; non interpreta simboli di censura.
  numerico <- !mancante & grepl("^[+-]?([0-9]+([.][0-9]*)?|[.][0-9]+)$", normalizzato)
  valore <- rep(NA_real_, length(x))
  valore[numerico] <- as.numeric(normalizzato[numerico])
  data.frame(originale = x, valore = valore, mancante = mancante,
             fallito = !mancante & !numerico, stringsAsFactors = FALSE)
}

esempi <- c("6,40", " 5.4 ", "ND", "", "errore", "<0,05")
prova <- converti_misura(esempi)
print(prova)
stopifnot(prova$valore[1] == 6.4, prova$mancante[3], prova$fallito[5])

Lettura del risultato

Il simbolo di censura non viene eliminato per ricavare un falso valore esatto. La grammatica non accetta notazione scientifica o separatori delle migliaia: se fossero previsti nel protocollo, occorrerebbe estendere e verificare la regola.

2. Applicare la stessa regola alle tre misure

Importiamo il file come testo e convertiamo ogni colonna misurata con la medesima funzione. Manteniamo separati oggetto originale, risultati della conversione e tabella numerica: così una trasformazione può essere controllata cella per cella.

R · codice commentato
# Conservare anche stringhe vuote e codici testuali prima di interpretarli.
raw <- carica_dati("fossili_da_controllare.csv", sep = ";",
                   colClasses = "character", na.strings = character(),
                   stringsAsFactors = FALSE)
stopifnot(nrow(raw) == 25L)

misure <- c("diametro_tot_um", "diametro_int_um", "diaframma_um")
conversioni <- lapply(raw[misure], converti_misura)
numerici <- raw[c("id", "morfotipo")]
for (nome in misure) numerici[[nome]] <- conversioni[[nome]]$valore
print(head(numerici, 6))
stopifnot(all(vapply(numerici[misure], is.numeric, logical(1))))

3. Produrre un audit per variabile

Contiamo mancanti e fallimenti separatamente per ciascuna misura. Questa tabella aiuta a capire se il problema deriva da informazione assente o da una rappresentazione inattesa; la colonna originale rimane disponibile per una revisione mirata.

R · codice commentato
audit <- do.call(rbind, lapply(names(conversioni), function(nome) {
  z <- conversioni[[nome]]
  data.frame(variabile = nome, celle = nrow(z), mancanti = sum(z$mancante),
             fallite = sum(z$fallito), numeriche = sum(is.finite(z$valore)))
}))
print(audit)
stopifnot(all(audit$celle == audit$mancanti + audit$fallite + audit$numeriche))
confronto <- data.frame(id = raw$id, testo = raw$diametro_tot_um,

Errore da riconoscere

Sopprimere gli avvisi di as.numeric senza un registro delle conversioni perde la distinzione fra dati assenti e testo inatteso. La soluzione controlla prima la grammatica e conserva esiti separati.

Risposta alla domanda

La conversione produce numeri, indicatori e corrispondenze con il testo originale. Ogni mancato calcolo ha una ragione leggibile; la verifica fisica delle misure resta un passaggio successivo e autonomo.
