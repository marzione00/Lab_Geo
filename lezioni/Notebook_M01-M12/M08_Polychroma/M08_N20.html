1. Due istruzioni, la stessa trasformazione

La prima chiamata standardizza dentro prcomp; la seconda riceve una matrice già standardizzata. Non centrare e scalare nuovamente Z rende esplicita la trasformazione già applicata.

R · codice commentato
# Seleziona le misure per nome: ID ed etichetta non entrano nella matrice.
r <- carica_dati("rocce_simulate.csv")
v <- c("SiO2", "CaO", "MgO", "FeO", "densita", "grana_mm", "colore", "fossili")
X <- as.matrix(r[v])
stopifnot(nrow(X)==90L, ncol(X)==8L, !anyDuplicated(r$id),
          all(is.finite(X)), all(apply(X,2,sd)>0))
Z <- scale(X)
D <- dist(Z)
pc_X <- prcomp(X,center=TRUE,scale.=TRUE)
pc_Z <- prcomp(Z,center=FALSE,scale.=FALSE)
c(errore_dev_standard=max(abs(pc_X$sdev-pc_Z$sdev)),
 errore_rotation=max(abs(pc_X$rotation-pc_Z$rotation)),
 errore_scores=max(abs(pc_X$x-pc_Z$x)))
stopifnot(max(abs(pc_X$sdev-pc_Z$sdev))<1e-10,
          max(abs(pc_X$x-pc_Z$x))<1e-10)

Lettura del risultato

Con lo stesso backend e questi dati, scores, rotazione e deviazioni standard coincidono. In confronti fra software o decomposizioni è comunque necessario considerare l’ambiguità del segno degli assi.

2. Collegamento con la decomposizione SVD

La decomposizione Z=UDV⊤Z=UDV^\top dà scores T=UDT=UD e autovalori λk=dk2/(n−1)\lambda_k=d_k^2/(n-1). La PCA di prcomp usa una decomposizione ai valori singolari; controlliamo la relazione senza confrontare segni arbitrari.

R · codice commentato
sv <- svd(Z)
autovalori_svd <- sv$d^2/(nrow(Z)-1)
data.frame(PC=1:ncol(Z),lambda_PCA=pc_X$sdev^2,lambda_SVD=autovalori_svd)
max(abs(Z-sv$u%*%diag(sv$d)%*%t(sv$v)))
# Cambia contemporaneamente segno a scores e vettore di un asse.
T2 <- pc_X$x; V2 <- pc_X$rotation
T2[,1] <- -T2[,1]; V2[,1] <- -V2[,1]
max(abs(pc_X$x%*%t(pc_X$rotation)-T2%*%t(V2)))

3. Proiettare nuovi casi con la scala conservata

La proiezione usa le medie e le deviazioni standard del fit: tnuovo=[(xnuovo−x‾)/s]Vt_{\mathrm{nuovo}}=[(x_{\mathrm{nuovo}}-\bar x)/s]V. Ricalcolare la scala sul nuovo insieme cambierebbe il sistema di riferimento.

R · codice commentato
# Tre righe vengono usate come esempio di input esterno, non come nuovo fit.
nuovi <- as.data.frame(X[c(1,31,61),,drop=FALSE])
previsti <- predict(pc_X,newdata=nuovi)
Zn <- sweep(sweep(as.matrix(nuovi),2,pc_X$center,"-"),2,pc_X$scale,"/")
manuali <- Zn%*%pc_X$rotation
round(previsti[,1:2],4)
max(abs(previsti-manuali))

Lettura del risultato

predict applica i parametri conservati nell’oggetto. L’oggetto stimato su Z con center=FALSE e scale.=FALSE richiede invece input già standardizzati nella medesima scala; i due oggetti non accettano indistintamente gli stessi dati grezzi.

Errore da riconoscere

Passare nuovi dati nelle unità originali al modello stimato su Z senza standardizzarli con le medie e le scale del fit originario.

Risposta alla domanda

La PCA è una sequenza definita di trasformazioni. Oggetto del modello, colonne, scale, autovalori e rotazione devono rimanere coerenti dalla stima alla proiezione.
