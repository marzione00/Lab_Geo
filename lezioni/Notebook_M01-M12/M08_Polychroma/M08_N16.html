1. Costruire e tagliare la gerarchia

Ward unisce progressivamente i gruppi scegliendo, a ogni passo, la fusione con minore aumento della somma quadratica interna. Usiamo ward.D2 e distanze euclidee calcolate su Z; non eleviamo le distanze al quadrato prima di passarle a R.

R · codice commentato
# Seleziona le misure per nome: ID ed etichetta non entrano nella matrice.
r <- carica_dati("rocce_simulate.csv")
v <- c("SiO2", "CaO", "MgO", "FeO", "densita", "grana_mm", "colore", "fossili")
X <- as.matrix(r[v])
stopifnot(nrow(X)==90L, ncol(X)==8L, !anyDuplicated(r$id),
          all(is.finite(X)), all(apply(X,2,sd)>0))
Z <- scale(X)
D <- dist(Z)
# Ward.D2 riceve le distanze euclidee, senza elevarle al quadrato a mano.
h <- hclust(D, method="ward.D2")
ward <- cutree(h, k=3)
plot(h,labels=FALSE,hang=-1,main="Gerarchia di Ward",xlab="90 campioni",
 sub="",ylab="Altezza di Ward.D2")
rect.hclust(h,k=3,border=c("#087C74","#C57E42","#7363AA"))
table(ward)

Il taglio produce tre gruppi da 30 casi. I rettangoli visualizzano una scelta di taglio; il dendrogramma descrive anche le fusioni più fini e quelle successive.

2. Ricostruire l’aumento della WSS

Per due gruppi A e B, ΔW=nAnBnA+nB∥μA−μB∥2\Delta W=\frac{n_A n_B}{n_A+n_B}\|\mu_A-\mu_B\|^2. In hclust con ward.D2 e ingresso euclideo, l’altezza memorizzata soddisfa h2=2ΔWh^2=2\Delta W. Ricostruiamo tutte le fusioni per controllare la convenzione.

R · codice commentato
membri <- vector("list",nrow(Z)-1)
delta <- numeric(nrow(Z)-1)
for(t in seq_len(nrow(h$merge))){
 # Valori negativi: singole righe; positivi: fusioni precedenti.
 a <- h$merge[t,1]; b <- h$merge[t,2]
 A <- if(a<0) -a else membri[[a]]
 B <- if(b<0) -b else membri[[b]]
 muA <- colMeans(Z[A,,drop=FALSE]); muB <- colMeans(Z[B,,drop=FALSE])
 delta[t] <- length(A)*length(B)/(length(A)+length(B))*sum((muA-muB)^2)
 membri[[t]] <- c(A,B)
}
c(errore_identita=max(abs(h$height^2/2-delta)),
 somma_incrementi=sum(delta),TSS=sum(Z^2))
tail(data.frame(fusione=seq_along(delta),altezza=h$height,delta_W=delta),5)

3. Confronto con k-means

Confrontiamo due procedure sulla stessa geometria: una gerarchica con fusioni irreversibili e una partizione ricalcolata per k fissato. Anche se la partizione coincide, i percorsi algoritmici restano diversi.

R · codice commentato
# Gli avvii multipli confrontano soluzioni locali sullo stesso spazio.

table(kmeans=km$cluster,Ward=ward)

Errore da riconoscere

Passare dist(Z)^2 a ward.D2 o interpretare l’altezza come aumento di WSS senza controllare la convenzione del software.

Risposta alla domanda

Il dendrogramma documenta una sequenza di fusioni. La formula degli incrementi permette di leggere correttamente le altezze e collegarle alla variabilità interna.
