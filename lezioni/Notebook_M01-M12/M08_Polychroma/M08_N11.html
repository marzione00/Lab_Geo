1. Tre centroidi nella matrice standardizzata

Per un numero fissato di gruppi, k-means cerca una partizione con piccola somma degli scarti quadratici interni: W=∑g∑i∈Cg∥zi−μg∥2W=\sum_g\sum_{i\in C_g}\|z_i-\mu_g\|^2. Il risultato dipende anche dagli avvii; qui confrontiamo 50 avvii con lo stesso seme.

R · codice commentato
# Seleziona le misure per nome: ID ed etichetta non entrano nella matrice.
r <- carica_dati("rocce_simulate.csv")
v <- c("SiO2", "CaO", "MgO", "FeO", "densita", "grana_mm", "colore", "fossili")
X <- as.matrix(r[v])
stopifnot(nrow(X)==90L, ncol(X)==8L, !anyDuplicated(r$id),
          all(is.finite(X)), all(apply(X,2,sd)>0))
Z <- scale(X)
D <- dist(Z)
# Gli avvii multipli confrontano soluzioni locali sullo stesso spazio.
set.seed(816)
km <- kmeans(Z, centers=3, nstart=50, iter.max=100)
km$size
round(km$centers,3)
c(WSS=km$tot.withinss,TSS=km$totss,quota_interna=km$tot.withinss/km$totss)

2. Verificare centroidi e obiettivo

Il centro di ogni gruppo è la media delle sue righe. Associamo a ciascun campione il proprio centro e sommiamo le distanze quadratiche; questa verifica rende esplicito l’obiettivo dell’algoritmo.

R · codice commentato
centri_manual <- do.call(rbind,lapply(1:3,function(g) colMeans(Z[km$cluster==g,,drop=FALSE])))
scarti <- Z-km$centers[km$cluster,,drop=FALSE]
distanza2 <- rowSums(scarti^2)
c(errore_centri=max(abs(centri_manual-km$centers)),
  WSS_diretta=sum(distanza2),WSS_R=km$tot.withinss)
stopifnot(abs(sum(distanza2)-km$tot.withinss)<1e-9)
Risultato dell’esecuzione
errore_centri   WSS_diretta         WSS_R 
  6.66134e-16   1.29498e+02   1.29498e+02

Lettura del risultato

Il calcolo diretto riproduce la WSS. Un campione lontano dal centro contribuisce molto perché lo scarto viene elevato al quadrato; per questo k-means è sensibile ai valori estremi.

3. Centroidi nel piano di visualizzazione

Proiettiamo nello stesso piano sia i campioni sia i centroidi, usando la rotazione della PCA. Il raggruppamento è stato calcolato nello spazio completo delle otto misure.

R · codice commentato
# La PCA conserva medie, scale e rotazione per eventuali nuovi campioni.
pc <- prcomp(X, center=TRUE, scale.=TRUE)
lambda <- pc$sdev^2
quota <- lambda/sum(lambda)
colori <- c("#087C74", "#C57E42", "#7363AA", "#1D7890", "#A17B19", "#657180", "#B55353")
centri_pc <- km$centers %*% pc$rotation
plot(pc$x[,1:2],col=colori[km$cluster],pch=19,asp=1,
 xlab="PC1",ylab="PC2")
points(centri_pc[,1:2],pch=4,cex=2.5,lwd=3)
text(centri_pc[,1:2],labels=paste("Centro",1:3),pos=3,cex=.8)

Lettura del risultato

Le croci indicano le medie proiettate. Le distanze visibili in due componenti possono essere inferiori a quelle usate realmente da k-means, perché il piano omette le componenti successive.

Errore da riconoscere

Interpretare il numero del cluster come un ordine o come una classe geologica già identificata. I numeri sono etichette arbitrarie.
