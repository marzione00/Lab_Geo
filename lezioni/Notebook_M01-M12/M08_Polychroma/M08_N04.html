1. Gli autovalori come varianze

In prcomp, sdev contiene le deviazioni standard delle componenti. La quota della componente k è λk/∑jλj\lambda_k/\sum_j\lambda_j. Per otto colonne standardizzate, la somma delle varianze è otto.

R · codice commentato
# Seleziona le misure per nome: ID ed etichetta non entrano nella matrice.
r <- carica_dati("rocce_simulate.csv")
v <- c("SiO2", "CaO", "MgO", "FeO", "densita", "grana_mm", "colore", "fossili")
X <- as.matrix(r[v])
stopifnot(nrow(X)==90L, ncol(X)==8L, !anyDuplicated(r$id),
          all(is.finite(X)), all(apply(X,2,sd)>0))
Z <- scale(X)
D <- dist(Z)
# La PCA conserva medie, scale e rotazione per eventuali nuovi campioni.
pc <- prcomp(X, center=TRUE, scale.=TRUE)
lambda <- pc$sdev^2
quota <- lambda/sum(lambda)
varianza <- data.frame(PC=1:8,lambda=lambda,quota=quota,
 cumulata=cumsum(quota))
varianza
c(somma_autovalori=sum(lambda),varianza_totale=sum(apply(Z,2,var)))

2. Quote singole e cumulate

Le barre mostrano il contributo separato di ogni componente; la linea cumulata mostra ciò che viene conservato includendole progressivamente. La soglia grafica del 90% è un criterio illustrativo, non una legge universale.

R · codice commentato
posizioni <- barplot(100*quota,names.arg=1:8,col="#087C74",

c(prime_due=100*sum(quota[1:2]),

3. Quanta informazione manca nel piano

La ricostruzione a due componenti è Ẑ2=T2V2⊤\hat Z_2=T_2V_2^\top. La frazione di somma quadratica persa coincide con la somma delle quote escluse.

R · codice commentato
Z2 <- pc$x[,1:2,drop=FALSE] %*% t(pc$rotation[,1:2,drop=FALSE])
perdita <- sum((Z-Z2)^2)/sum(Z^2)
c(perdita_quadratica=perdita,quota_esclusa=1-sum(quota[1:2]))
stopifnot(abs(perdita-(1-sum(quota[1:2])))<1e-10)
Risultato dell’esecuzione

Lettura del risultato

La perdita è circa il 13,41%. Si tratta di una misura quadratica sulla scala standardizzata; non significa che il 13,41% dei campioni sia sbagliato o che siano state eliminate intere variabili.

data.frame(q=1:8,perdita=vapply(1:8,function(q) {

   t(pc$rotation[,seq_len(q),drop=FALSE])
 sum((Z-rec)^2)/sum(Z^2)

Errore da riconoscere

Una quota globale elevata può nascondere una variabile poco rappresentata. La qualità della proiezione va valutata anche rispetto alle proprietà scientificamente rilevanti.

Risposta alla domanda

Le prime due componenti conservano l’86,59% della varianza standardizzata, con una perdita quadratica del 13,41%. Il numero di componenti dipende dall’uso della rappresentazione.
