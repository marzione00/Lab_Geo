Come distinguere la probabilità assegnata a un evento dalla frequenza che osserviamo in poche prove?

1. Dichiarare il modello prima delle estrazioni

Definiamo successo come rilevamento di un segnale. rbinom con size = 1 genera l’indicatore dell’evento: uno per successo, zero per insuccesso. La probabilità p appartiene al modello; i singoli esiti rimangono variabili.

R · codice commentato
set.seed(401)
p <- .30
n <- 20
# size = 1 produce una prova di Bernoulli; n e il numero di prove generate.
indicatore <- rbinom(n, size = 1, prob = p)
print(data.frame(prova = seq_len(n), segnale = indicatore))
stopifnot(all(indicatore %in% c(0, 1)))
successi <- sum(indicatore)
frequenza <- mean(indicatore)
print(c(p_modello = p, successi = successi, frequenza_osservata = frequenza))

Lettura del risultato

La media di un indicatore è una proporzione perché la somma conta gli uno. Una frequenza diversa da 0,30 in venti prove è compatibile con il modello e non dimostra che la probabilità sia cambiata.

2. Seguire l'accumulo delle prove

La frequenza cumulata usa le prime k osservazioni per ogni posizione k. La traiettoria rende visibili oscillazioni anche dopo molti insuccessi o successi consecutivi; non esiste un obbligo di compensazione nella prova successiva.

R · codice commentato
k <- seq_along(indicatore)
# Il denominatore cresce insieme al numero di prove effettivamente accumulate.
frequenza_cumulata <- cumsum(indicatore) / k
plot(k, frequenza_cumulata, type = "b", pch = 16, ylim = c(0, 1),
     col = "#1D7890", xlab = "Prove accumulate", ylab = "Frequenza del segnale")
abline(h = p, col = "#C57E42", lty = 2, lwd = 2)
stopifnot(tail(frequenza_cumulata, 1) == frequenza)

Lettura del risultato

La linea orizzontale è un parametro noto della simulazione, non una stima ottenuta dagli esiti. L’indipendenza implica che la probabilità della prova seguente resti p, qualunque sia la sequenza precedente.

3. Ripetere l'intero esperimento

Simuliamo molti esperimenti, ciascuno composto da venti prove. Qui B conta le repliche dell’esperimento, mentre n conta le prove entro una replica: confondere i due numeri cambierebbe la domanda.

R · codice commentato
B <- 2000
# Ogni replica ora contiene n prove: B conta gli esperimenti, non le prove interne.
frequenze <- rbinom(B, size = n, prob = p) / n
print(c(media_frequenze = mean(frequenze), sd_frequenze = sd(frequenze),
        sd_teorica = sqrt(p * (1 - p) / n)))
hist(frequenze, breaks = seq(-.025, 1.025, by = .05), col = "#1D7890",
     xlab = "Frequenza in un esperimento di 20 prove", ylab = "Repliche (n)",
     main = "Variazione fra esperimenti")
abline(v = p, col = "#C57E42", lwd = 2)

Lettura del risultato

La distribuzione delle frequenze è centrata vicino al valore assegnato, ma conserva una dispersione determinata da n. Aumentare B rende più precisa la sua descrizione simulata; non riduce la variabilità di un esperimento di venti prove.

Variante svolta

Portare a duecento le prove entro ciascun esperimento e confrontare la dispersione delle frequenze.

R · codice commentato
n_grande <- 200
frequenze_grandi <- rbinom(B, size = n_grande, prob = p) / n_grande
print(rbind(n20 = c(media = mean(frequenze), sd = sd(frequenze)),
            n200 = c(media = mean(frequenze_grandi), sd = sd(frequenze_grandi))))
print(c(sd_teorica_20 = sqrt(p * (1 - p) / n),
        sd_teorica_200 = sqrt(p * (1 - p) / n_grande)))

La deviazione standard teorica della frequenza diminuisce come uno su radice di n. Il risultato riguarda esperimenti indipendenti con probabilità costante e non garantisce che ogni singola frequenza più lunga sia più vicina a p.

Errore da riconoscere

Non interpretare p = 0,30 come la promessa di esattamente sei successi su venti. Non aspettarsi che una sequenza di insuccessi renda più probabile il prossimo successo.

Risposta alla domanda

La probabilità è una regola del modello, la frequenza un risultato dell’esperimento. La simulazione mostra come frequenze diverse possano nascere dallo stesso parametro e distingue la numerosità delle prove dal numero di repliche.
