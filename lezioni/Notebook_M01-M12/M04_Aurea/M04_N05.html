La binomiale: numero di successi in n prove

M04_N05 · Aurea · soluzione eseguita e commentata

Quale distribuzione descrive il numero di segnali in dieci prove indipendenti con uguale probabilità di successo?

1. Calcolare tutte le probabilità

La binomiale richiede un numero fissato di prove, indipendenza e probabilità di successo costante. dbinom calcola la massa di probabilità dei conteggi interi; valori intermedi come due e mezzo successi non appartengono al modello.

R · codice commentato
n <- 10
p <- .30
k <- 0:n
# dbinom restituisce probabilita di conteggi interi, non altezze di una densita continua.
massa <- dbinom(k, size = n, prob = p)
tab <- data.frame(successi = k, probabilita = massa)
print(tab)
stopifnot(all(massa >= 0), abs(sum(massa) - 1) < 1e-12)

Lettura del risultato

La probabilità di ciascun conteggio comprende tutti gli ordinamenti delle prove che producono quel numero di successi. Per questo non basta moltiplicare p per se stesso senza considerare le combinazioni possibili.

2. Ricostruire media e varianza

Il valore atteso è la somma dei conteggi pesati per le loro probabilità. La varianza pesa gli scarti quadratici dal valore atteso; confrontiamo le somme con le formule n per p e n per p per uno meno p.

R · codice commentato
# Il valore atteso e una media ponderata dalle probabilita di tutti gli esiti.
media_somma <- sum(k * massa)
varianza_somma <- sum((k - media_somma)^2 * massa)
media_formula <- n * p
varianza_formula <- n * p * (1 - p)
print(rbind(somme = c(media = media_somma, varianza = varianza_somma),
            formule = c(media = media_formula, varianza = varianza_formula)))
stopifnot(abs(media_somma - media_formula) < 1e-12)
stopifnot(abs(varianza_somma - varianza_formula) < 1e-12)
Risultato dell’esecuzione

somme       3      2.1

Lettura del risultato

Il valore atteso non promette un conteggio esatto in ogni replica. La varianza è una proprietà della distribuzione dei conteggi e dipende sia dal numero di prove sia dalla probabilità assegnata.

3. Confrontare teoria e repliche

Generiamo duemila conteggi, ognuno relativo a dieci prove. Il grafico a segmenti rappresenta probabilità in punti discreti e i punti sovrapposti mostrano le frequenze delle simulazioni.

R · codice commentato
set.seed(405)
B <- 2000
estratti <- rbinom(B, size = n, prob = p)
# Il fattore con livelli espliciti conserva anche i conteggi mai osservati.
frequenze <- as.numeric(table(factor(estratti, levels = k))) / B
plot(k, massa, type = "h", lwd = 4, col = "#1D7890",
     xlab = "Successi in 10 prove", ylab = "Probabilita o frequenza")
points(k, frequenze, pch = 16, col = "#C57E42")
print(c(media_simulata = mean(estratti), varianza_simulata = var(estratti)))
legend("topright", c("Modello", "Simulazione"), col = c("#1D7890", "#C57E42"), pch = c(NA, 16), lty = c(1, NA), bty = "n")

Lettura del risultato

Le frequenze non coincidono esattamente con la massa teorica perché B è finito. Per rappresentare esiti non osservati manteniamo tutti i livelli da zero a dieci nel fattore prima di costruire la tabella.

Scambiare successo e insuccesso riflette la distribuzione rispetto a cinque. La media cambia e la varianza resta uguale perché il prodotto p per uno meno p è simmetrico.

Errore da riconoscere

Non confondere n, prove dentro un esperimento, con B, esperimenti simulati. Se le probabilità cambiano fra prove o le prove sono dipendenti, la binomiale semplice può essere inadeguata.

Risposta alla domanda

La binomiale collega una regola per singole prove a una distribuzione dei conteggi. Le somme di probabilità verificano le formule, mentre la simulazione mostra le fluttuazioni attese in un numero finito di repliche.
