1. Legare parametro ed esposizione

Il tasso possiede un’unità, eventi per ora; lambda è il numero atteso nell’intervallo specificato. Un parametro senza durata sarebbe ambiguo. Il modello assume tasso costante e assenza di raggruppamenti o dipendenze fra eventi.

R · codice commentato
tasso <- 3
ore <- c(1, 2)
# Il tasso per ora va moltiplicato per una durata espressa in ore.
lambda <- tasso * ore
tab <- data.frame(ore = ore, lambda = lambda,
  nessun_evento = dpois(0, lambda), almeno_uno = ppois(0, lambda, lower.tail = FALSE))
print(tab)
stopifnot(max(abs(tab$nessun_evento + tab$almeno_uno - 1)) < 1e-12)
Risultato dell’esecuzione
ore lambda nessun_evento almeno_uno
1   1      3    0.04978707   0.950213
2   2      6    0.00247875   0.997521

Lettura del risultato

Raddoppiare la durata raddoppia il conteggio atteso, ma non raddoppia tutte le probabilità. La probabilità di almeno un evento resta limitata a uno e cambia secondo la distribuzione del conteggio.

2. Rappresentare il supporto infinito

La Poisson ammette qualsiasi intero non negativo. Per il grafico scegliamo fino a quindici eventi e calcoliamo anche la probabilità della coda omessa: la somma delle barre visibili non è necessariamente uno.

R · codice commentato
k <- 0:15
p1 <- dpois(k, lambda = lambda[1])
p2 <- dpois(k, lambda = lambda[2])
matplot(k, cbind(p1, p2), type = "b", pch = c(16, 17),
        col = c("#1D7890", "#C57E42"), xlab = "Eventi osservati", ylab = "Probabilita")
legend("topright", c("1 ora", "2 ore"), col = c("#1D7890", "#C57E42"), pch = c(16, 17), bty = "n")
# Il modello ha supporto infinito: quantifichiamo la parte non mostrata nel grafico.
code <- ppois(15, lambda = lambda, lower.tail = FALSE)
print(data.frame(ore = ore, probabilita_oltre_15 = code))
stopifnot(max(abs(c(sum(p1), sum(p2)) + code - 1)) < 1e-12)
Risultato dell’esecuzione
ore probabilita_oltre_15
1   1          1.24080e-07
2   2          5.09098e-04

Lettura del risultato

Il troncamento riguarda soltanto la figura, non il modello. Le distribuzioni si spostano e si allargano con lambda; il tasso resta identico, mentre l’esposizione distingue i due conteggi.

3. Verificare media e varianza

Per una Poisson semplice media e varianza sono entrambe lambda. Simuliamo esposizioni uguali per confrontare queste proprietà; con dati reali esposizioni diverse andrebbero considerate prima di interpretare una varianza elevata.

R · codice commentato
set.seed(408)
B <- 3000
una_ora <- rpois(B, lambda = lambda[1])
# L esposizione doppia cambia lambda, mentre il tasso di eventi resta costante.
due_ore <- rpois(B, lambda = lambda[2])
risultati <- rbind(una_ora = c(media = mean(una_ora), varianza = var(una_ora)),
                   due_ore = c(media = mean(due_ore), varianza = var(due_ore)))
print(risultati)
print(c(tasso_stimato_1ora = mean(una_ora), tasso_stimato_2ore = mean(due_ore) / 2))

Lettura del risultato

Le medie e le varianze simulate oscillano attorno ai rispettivi valori teorici. Dividere il conteggio medio per la durata permette di confrontare i tassi, mentre confrontare i conteggi grezzi confonderebbe attività ed esposizione.

Variante svolta

Calcolare il conteggio atteso e la probabilità di almeno un evento in trenta minuti.

R · codice commentato
minuti <- 30
durata_ore <- minuti / 60
lambda_breve <- tasso * durata_ore
prob_breve <- ppois(0, lambda_breve, lower.tail = FALSE)
print(c(durata_ore = durata_ore, lambda = lambda_breve, almeno_uno = prob_breve))
stopifnot(abs(lambda_breve - 1.5) < 1e-12)
print(dpois(0:5, lambda_breve))
Risultato dell’esecuzione
durata_ore     lambda almeno_uno 
   0.50000    1.50000    0.77687 
[1] 0.2231302 0.3346952 0.2510214 0.1255107 0.0470665 0.0141200

La conversione dei minuti in ore è necessaria perché il tasso è espresso per ora. Moltiplicare direttamente tre per trenta produrrebbe un conteggio atteso sessanta volte troppo grande.

Errore da riconoscere

Non confrontare conteggi osservati in durate o superfici diverse senza includere l’esposizione. Non concludere che il modello vale soltanto perché media e varianza sono simili in un piccolo campione.

Risposta alla domanda

Il parametro del conteggio dipende da tasso ed esposizione. Dichiarare le unità evita errori di scala; probabilità, media e varianza restano proprietà di un modello che richiede eventi indipendenti e un tasso adeguatamente costante.
