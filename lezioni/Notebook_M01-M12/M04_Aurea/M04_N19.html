1. Tradurre la consegna in soglie

Definiamo media, deviazione standard e bordi nella stessa unità. Il problema riguarda una singola densità dal modello assegnato; non la media di un campione e non l’incertezza di stima dei parametri.

R · codice commentato
mu <- 2.65
sigma <- .06
a <- 2.60
b <- 2.70
stopifnot(sigma > 0, a < b)
# Le soglie e i parametri sono tutti espressi in g/cm^3.
prob_esatta <- pnorm(b, mean = mu, sd = sigma) - pnorm(a, mean = mu, sd = sigma)
print(c(limite_inferiore = a, limite_superiore = b, probabilita = prob_esatta))
print(c(prob_fuori = pnorm(a, mu, sigma) + pnorm(b, mu, sigma, lower.tail = FALSE)))
Risultato dell’esecuzione
limite_inferiore limite_superiore      probabilita 
        2.600000         2.700000         0.595343 
prob_fuori 
  0.404657

Lettura del risultato

La probabilità esterna è la somma delle due code disgiunte. La loro somma con la probabilità interna deve essere uno; questo controllo aiuta a individuare bordi invertiti o sottrazioni sbagliate.

2. Verificare sulla scala standard

Le soglie standardizzate indicano quante deviazioni standard separano i bordi dalla media. Poiché l’intervallo è simmetrico, possiamo usare anche due volte la cumulativa della soglia positiva meno uno.

R · codice commentato
za <- (a - mu) / sigma
zb <- (b - mu) / sigma
prob_z <- pnorm(zb) - pnorm(za)
# La formula abbreviata e valida soltanto per soglie simmetriche rispetto a mu.
prob_simmetria <- 2 * pnorm(zb) - 1
print(c(za = za, zb = zb, prob_z = prob_z, prob_simmetria = prob_simmetria))
stopifnot(abs(za + zb) < 1e-12)
stopifnot(abs(prob_z - prob_esatta) < 1e-12,
          abs(prob_simmetria - prob_esatta) < 1e-12)
Risultato dell’esecuzione
za             zb         prob_z prob_simmetria 
     -0.833333       0.833333       0.595343       0.595343

Lettura del risultato

La scorciatoia della simmetria funziona perché i bordi sono equidistanti dalla media. Per un intervallo spostato occorre tornare alla differenza delle cumulative, senza forzare una formula che non rappresenta più l’evento.

3. Controllare mediante repliche

Generiamo cinquemila valori e calcoliamo la quota interna. L’errore standard degli indicatori quantifica la precisione della verifica numerica; la probabilità teorica resta il riferimento del modello.

R · codice commentato
set.seed(419)
B <- 5000
x <- rnorm(B, mu, sigma)
# La condizione deve riprodurre lo stesso intervallo usato nel calcolo con pnorm.
evento <- x >= a & x <= b
q <- mean(evento)
se_mc <- sqrt(q * (1 - q) / B)
print(c(probabilita_teorica = prob_esatta, quota_simulata = q,
        errore_standard_mc = se_mc, scarto = q - prob_esatta))
hist(x, breaks = "FD", col = "#D5E9EE", border = "white",
     xlab = "Densita (g/cm^3)", ylab = "Repliche (n)", main = "Intervallo di interesse")
abline(v = c(a, b), col = "#C57E42", lwd = 2, lty = 2)
Risultato dell’esecuzione
probabilita_teorica      quota_simulata  errore_standard_mc              scarto 
         0.59534324          0.60500000          0.00691339          0.00965676

Lettura del risultato

Una differenza di alcune unità dell’errore standard merita un controllo del codice e del modello generatore, ma non si deve pretendere uguaglianza esatta. Il seme permette di rivedere la stessa esecuzione con gli studenti.

Variante svolta

Dimezzare sigma mantenendo la media e l’intervallo fisico, quindi ripetere il calcolo analitico.

R · codice commentato
sigma_nuova <- sigma / 2
prob_nuova <- pnorm(b, mu, sigma_nuova) - pnorm(a, mu, sigma_nuova)
print(data.frame(sigma = c(sigma, sigma_nuova),
                 probabilita_intervallo = c(prob_esatta, prob_nuova)))
print(c(za_nuovo = (a - mu) / sigma_nuova, zb_nuovo = (b - mu) / sigma_nuova))
stopifnot(prob_nuova > prob_esatta)
stopifnot(prob_nuova < 1)
Risultato dell’esecuzione

1  0.06               0.595343
2  0.03               0.904419
za_nuovo zb_nuovo 
-1.66667  1.66667

La distribuzione più concentrata colloca più probabilità nello stesso intervallo centrale. L’aumento non significherebbe automaticamente miglioramento di uno strumento se sigma rappresentasse invece eterogeneità naturale: il significato del parametro va dichiarato.

Errore da riconoscere

Non confondere sigma con sigma diviso radice di n: il problema riguarda una singola estrazione, non una media. Non cambiare contemporaneamente soglie e deviazione standard senza distinguere i due effetti.

Risposta alla domanda

Il percorso completo parte dall’evento fisico, verifica unità e soglie e confronta tre calcoli coerenti. La simulazione aggiunge un controllo riproducibile con precisione dichiarata, mentre l’interpretazione dipende dal significato del modello assegnato.
