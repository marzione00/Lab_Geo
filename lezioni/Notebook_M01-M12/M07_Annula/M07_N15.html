1. Media e scala sono parametri stimati

La standardizzazione z=(x−μ)/sxz=(x-\mu)/s_x richiede media e deviazione standard. Quando la trasformazione fa parte di una procedura predittiva, questi parametri vanno appresi nel training.

R · codice commentato
# Ogni riga identifica un fossile simulato.
f <- carica_dati("fossili_simulati.csv")
f$morfotipo <- factor(f$morfotipo, levels=c("Rounded", "Spiky"))
x <- f$diametro_tot_um
y <- f$diametro_int_um
stopifnot(nrow(f)==160L, !anyDuplicated(f$id),
          all(is.finite(x)), all(is.finite(y)))
# Partizione fissata prima del confronto dei modelli.
# Nel CSV didattico ogni quinto individuo forma il test.
is_test <- seq_len(nrow(f)) %% 5L == 0L
train <- f[!is_test, ]
test <- f[is_test, ]
stopifnot(nrow(train)==128L, nrow(test)==32L,
          length(intersect(train$id, test$id))==0L)
mu <- mean(train$diametro_tot_um)
sx <- sd(train$diametro_tot_um)
stopifnot(sx>0)
train$z <- (train$diametro_tot_um-mu)/sx
test$z <- (test$diametro_tot_um-mu)/sx
c(media_training=mean(train$z),sd_training=sd(train$z),
  media_test=mean(test$z),sd_test=sd(test$z))
Risultato dell’esecuzione
media_training    sd_training     media_test        sd_test 
  -3.16899e-16    1.00000e+00   -2.00512e-01    1.03562e+00

Lettura del risultato

Training ha media zero e deviazione standard uno per costruzione. Il test può avere media e scala diverse: conserva le proprie differenze, espresse con la scala del training.

2. Le previsioni sulla stessa scala

Una regressione lineare semplice con intercetta conserva le previsioni dopo una trasformazione affine invertibile del predittore, purché la stessa trasformazione sia applicata a tutti i casi.

R · codice commentato
m_x <- lm(diametro_int_um~diametro_tot_um,data=train)
m_z <- lm(diametro_int_um~z,data=train)
p_x <- predict(m_x,test)
p_z <- predict(m_z,test)
c(massima_differenza=max(abs(p_x-p_z)))
coef(m_z)
stopifnot(max(abs(p_x-p_z))<1e-10)

Lettura del risultato

L’intercetta ora riguarda il diametro totale medio del training. La pendenza indica una variazione della risposta per una deviazione standard del predittore. L’invarianza delle previsioni qui è una proprietà specifica di questa parametrizzazione.

3. La trasformazione all’interno di ogni fold

Nella validazione interna ripetiamo anche la stima di media e scala. Una trasformazione appresa su tutto il dataset prima della divisione può trasferire informazione fra parti che si intendono separare.

R · codice commentato
set.seed(714)
fold <- sample(rep(1:5,length.out=nrow(train)))
scale_cv <- do.call(rbind,lapply(1:5,function(k) {
 a <- train[fold!=k,];b <- train[fold==k,]
 media_k <- mean(a$diametro_tot_um)
 sd_k <- sd(a$diametro_tot_um)
 a$z <- (a$diametro_tot_um-media_k)/sd_k
 b$z <- (b$diametro_tot_um-media_k)/sd_k
 m <- lm(diametro_int_um~z,data=a)
 data.frame(fold=k,media=media_k,sd=sd_k,
  RMSE=metriche(b$diametro_int_um,predict(m,b))["RMSE"])
}))
scale_cv

Variante svolta

Standardizzare il test con la propria media e mostrare l’errore di applicare il modello addestrato sulla scala del training.

Il modello interpreta z=0 come la media del training. Ricalibrare lo zero sul test cambia il significato del predittore e quindi le previsioni.

Errore da riconoscere

Standardizzare separatamente ogni insieme non significa applicare la stessa trasformazione.

Risposta alla domanda

La procedura deve salvare e riutilizzare i parametri di trasformazione insieme ai coefficienti del modello.
