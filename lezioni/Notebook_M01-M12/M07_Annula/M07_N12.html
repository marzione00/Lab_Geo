Prerequisiti. Vettori, data frame, indicizzazione e funzioni di base in R.

Dati e unità. Fossili simulati del corso: 160 individui, 80 Rounded e 80 Spiky. Diametri e spessori sono espressi in micrometri. Nel generatore, diametro interno = diametro totale − 2 × spessore. La relazione contiene quindi un vincolo geometrico noto.

1. Le cinque partizioni

Dividiamo i 128 casi di training in cinque gruppi. A turno un gruppo serve alla valutazione interna e gli altri quattro alla stima. Il seme rende la divisione riproducibile.

R · codice commentato
# Ogni riga identifica un fossile simulato.
f <- carica_dati("fossili_simulati.csv")
f$morfotipo <- factor(f$morfotipo, levels=c("Rounded", "Spiky"))
x <- f$diametro_tot_um
y <- f$diametro_int_um
stopifnot(nrow(f)==160L, !anyDuplicated(f$id),
          all(is.finite(x)), all(is.finite(y)))
# Partizione fissata prima del confronto dei modelli.
# Nel CSV didattico ogni quinto individuo forma il test.
is_test <- seq_len(nrow(f)) %% 5L == 0L
train <- f[!is_test, ]
test <- f[is_test, ]
stopifnot(nrow(train)==128L, nrow(test)==32L,
          length(intersect(train$id, test$id))==0L)
set.seed(714)
fold <- sample(rep(1:5,length.out=nrow(train)))
table(fold)
formule <- list(lineare=diametro_int_um~diametro_tot_um,
 con_morfotipo=diametro_int_um~diametro_tot_um+morfotipo,
 polinomio3=diametro_int_um~poly(diametro_tot_um,3))

I fold contengono 25 o 26 casi. Questa suddivisione presuppone che i singoli fossili sintetici siano unità adeguate per lo scambio fra partizioni.

2. Ristimare il modello a ogni giro

Il ciclo ripete tutta la stima. poly() impara la base polinomiale nella porzione di stima e predict() applica quella stessa base ai casi lasciati fuori.

R · codice commentato
cv <- do.call(rbind,lapply(names(formule),function(nome) {
 do.call(rbind,lapply(1:5,function(k) {
  tr <- train[fold!=k,]
  va <- train[fold==k,]
  m <- lm(formule[[nome]],data=tr)
  pr <- predict(m,newdata=va)
  met <- metriche(va$diametro_int_um,pr)
  data.frame(modello=nome,fold=k,
             MAE=unname(met["MAE"]),RMSE=unname(met["RMSE"]))
 }))
}))

3. Scelta dichiarata dal criterio

Come nel laboratorio originale, usiamo la media dei cinque RMSE di fold. È una scelta esplicita, leggermente diversa dal RMSE ottenuto aggregando tutti gli errori lasciati fuori.

R · codice commentato
media_cv <- aggregate(cbind(MAE,RMSE)~modello,cv,mean)

Risposta alla domanda

La validazione interna seleziona la formula. L’errore del candidato vincente in questa stessa scelta non è ancora una valutazione esterna della procedura completa.
