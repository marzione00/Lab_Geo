Come cambia il confronto fra previsioni quando pochi errori sono particolarmente grandi?

1. Un calcolo controllabile a mano

Usiamo tre osservazioni per rendere esplicite le operazioni. Gli errori 0, 0 e −3 hanno MAE 1 e RMSE 3\sqrt{3}.

R · codice commentato
osservato <- c(1,2,3)
previsto <- c(1,2,6)
e <- osservato-previsto
data.frame(osservato,previsto,errore=e,assoluto=abs(e),quadrato=e^2)
metriche(osservato,previsto)
Risultato dell’esecuzione
osservato previsto errore assoluto quadrato
1         1        1      0        0        0
2         2        2      0        0        0
3         3        6     -3        3        9
    MAE    RMSE 
1.00000 1.73205

Lettura del risultato

La radice riporta il RMSE nell’unità originale. Il quadrato, applicato prima della media, fa pesare molto l’errore di ampiezza 3.

2. Due modelli con errori distribuiti diversamente

Confrontiamo una regola con errori moderati su tutti i casi e una con molti errori nulli ma un grande errore. La graduatoria dipende dalla perdita ritenuta pertinente.

R · codice commentato
vero <- rep(0,10)
regola_A <- rep(.8,10)
regola_B <- c(rep(0,9),3)
rbind(A=metriche(vero,regola_A),B=metriche(vero,regola_B))
barplot(rbind(abs(vero-regola_A),abs(vero-regola_B)),beside=TRUE,
 col=c("#087C74","#C57E42"),xlab="Caso",ylab="Errore assoluto")
legend("topleft",c("A","B"),fill=c("#087C74","#C57E42"),bty="n")
Risultato dell’esecuzione
MAE     RMSE
A 0.8 0.800000
B 0.3 0.948683

Lettura del risultato

MAE preferisce B: 0,30 contro 0,80. RMSE preferisce A: 0,80 contro circa 0,95. Le due graduatorie rispondono a pesi diversi assegnati agli errori grandi.

3. Le metriche sul caso dei fossili

Torniamo alla procedura fissata nei notebook precedenti. Il confronto con il riferimento usa sia MAE sia RMSE, mantenendo la scelta del modello basata sul criterio già dichiarato.

R · codice commentato
# Ogni riga identifica un fossile simulato.
f <- carica_dati("fossili_simulati.csv")
f$morfotipo <- factor(f$morfotipo, levels=c("Rounded", "Spiky"))
x <- f$diametro_tot_um
y <- f$diametro_int_um
stopifnot(nrow(f)==160L, !anyDuplicated(f$id),
          all(is.finite(x)), all(is.finite(y)))
# Partizione fissata prima del confronto dei modelli.
# Nel CSV didattico ogni quinto individuo forma il test.
is_test <- seq_len(nrow(f)) %% 5L == 0L
train <- f[!is_test, ]
test <- f[is_test, ]
stopifnot(nrow(train)==128L, nrow(test)==32L,
          length(intersect(train$id, test$id))==0L)
# La funzione ripete la stima su cinque partizioni del solo training.
# Il suo codice completo e' spiegato nel notebook N12.
scelta <- seleziona_modello(train, seme=714)
finale <- lm(scelta$formule[[scelta$nome]], data=train)
p <- predict(finale,test)
p0 <- rep(mean(train$diametro_int_um),nrow(test))
rbind(riferimento=metriche(test$diametro_int_um,p0),
 modello=metriche(test$diametro_int_um,p))
Risultato dell’esecuzione
MAE     RMSE
riferimento 0.741510 1.002913
modello     0.172135 0.199439

Lettura del risultato

In questo esempio il modello con morfotipo migliora entrambe le metriche. Questo accordo non elimina il bisogno di controllare dove si concentrano gli errori e quale popolazione il test rappresenta.

Variante svolta

Moltiplicare tutti i valori dell’esempio a tre casi per 1000: come cambiano MAE e RMSE?

R · codice commentato
rbind(unita_iniziale=metriche(osservato,previsto),
       unita_mille_volte_piu_piccola=metriche(1000*osservato,1000*previsto))
Risultato dell’esecuzione
MAE       RMSE
unita_iniziale                   1    1.73205
unita_mille_volte_piu_piccola 1000 1732.05081

Entrambe le metriche si moltiplicano per 1000. Per confrontare studi o strumenti, unità della risposta e popolazione dei casi devono essere coerenti.

Errore da riconoscere

Scegliere dopo aver visto i risultati la metrica che favorisce il proprio modello rende il confronto ambiguo.

Risposta alla domanda

La metrica esprime una scelta sul costo degli errori. La graduatoria fra modelli può cambiare quando cambia quella scelta.
