M09_N03 · Borealis · soluzione eseguita e commentata

La media che abbiamo ricostruito coincide con il CSV mensile distribuito dal corso?

Sorgente R MarkdownCome eseguire il notebook

Prima di iniziare

  • Controllare una trasformazione dai dati originari.

  • Allineare le tabelle mediante una chiave.

  • Definire una tolleranza numerica motivata.

Prerequisiti. Lettura di CSV, vettori, indicizzazione e funzioni di base in R. I blocchi vanno eseguiti nell’ordine all’interno del singolo notebook.

Dati e unità. Archivio storico CO₂ 1958–2001, copia del dataset settimanale statsmodels attribuito a Keeling, Whorf e CDIAC. Le concentrazioni sono espresse in ppm. Le medie mensili del corso derivano dai valori settimanali assegnati al mese della data e differiscono per definizione da una serie mensile ufficiale.

Percorso dello svolgimento

  1. Ricostruire senza copiare il risultato
  2. Unire mediante la data
  3. Ammettere soltanto l’arrotondamento atteso

1. Ricostruire senza copiare il risultato

Ripartiamo dal file settimanale e ripetiamo la definizione dell’aggregato. Questo controllo verifica che dati e procedura siano coerenti fra loro.

R · codice commentato
w <- carica_dati("co2_settimanale_storica.csv")
w$data <- as.Date(w$data)
w <- w[order(w$data), ]
# La data di riferimento assegna ciascuna settimana a un mese.
gruppi <- split(w$co2, format(w$data, "%Y-%m"))
m <- do.call(rbind, lapply(names(gruppi), function(k) {
  z <- gruppi[[k]]
  n <- sum(!is.na(z))
  data.frame(data=as.Date(paste0(k, "-01")),
    co2_ppm=if (n > 0) mean(z, na.rm=TRUE) else NA_real_,
    n_settimane=n)
}))
rownames(m) <- NULL
riferimento <- carica_dati("co2_mensile_derivata.csv")
riferimento$data <- as.Date(riferimento$data)
c(mesi_calcolo=nrow(m), mesi_riferimento=nrow(riferimento))
Risultato dell’esecuzione

Lettura del risultato

I due archivi contengono lo stesso numero di mesi. La sola uguaglianza delle lunghezze non garantisce ancora l’allineamento temporale.

2. Unire mediante la data

La data è la chiave del confronto. Un’unione completa rende visibili eventuali mesi presenti soltanto in uno dei file, evitando sottrazioni fra righe non corrispondenti.

R · codice commentato
confronto <- merge(m, riferimento, by="data", all=TRUE,
 suffixes=c("_calcolo","_corso"))
stopifnot(nrow(confronto)==nrow(m), nrow(confronto)==nrow(riferimento),
 identical(is.na(confronto$co2_ppm_calcolo),is.na(confronto$co2_ppm_corso)),
 all(confronto$n_settimane_calcolo==confronto$n_settimane_corso))
head(confronto, 4)

3. Ammettere soltanto l’arrotondamento atteso

Il CSV riporta sei cifre decimali. Confrontiamo le medie mediante una tolleranza coerente con tale esportazione, senza richiedere l’identità esatta della rappresentazione binaria.

R · codice commentato
confronto$scarto <- confronto$co2_ppm_calcolo-confronto$co2_ppm_corso
massimo <- max(abs(confronto$scarto), na.rm=TRUE)
stopifnot(massimo<1e-5)
massimo
plot(confronto$data, confronto$scarto, type="h", col="#087C74",
 xlab="Data", ylab="Scarto (ppm)")
abline(h=0, col="grey60")
Risultato dell’esecuzione
[1] 3.33333e-07

Lettura del risultato

Lo scarto massimo è circa 3,33 × 10⁻⁷ ppm, compatibile con la scrittura a sei decimali. Non è un segnale ambientale e non costituisce un errore di aggregazione.
