Quando mancano le categorie

M03_N03 · Iride · soluzione eseguita e commentata

Quale percentuale di Spiky possiamo riportare se alcuni fossili non sono stati classificati?

Prima di iniziare

  • Distinguere categoria assente e classificazione mancante.

Prerequisiti. Valori NA, filtri logici, table e somme di condizioni.

1. Costruire e mostrare il problema

Lasciamo intatto il file originale. Nella copia rimuoviamo le prime sei etichette: NA rappresenta una classificazione sconosciuta, non un terzo morfotipo biologico e neppure l’assenza di fossili.

R · codice commentato
f <- carica_dati("fossili_simulati.csv")
incompleti <- f
# La modifica riguarda una copia: le etichette del file originale restano disponibili.
incompleti$morfotipo[1:6] <- NA_character_
# useNA conserva la classe dei dati non classificati nella tabella.
print(table(incompleti$morfotipo, useNA = "ifany"))
noti <- !is.na(incompleti$morfotipo)
print(c(totale = nrow(incompleti), classificati = sum(noti),
        non_classificati = sum(!noti)))

Lettura del risultato

La tabella rende visibile quanta informazione manca. Eliminare le righe con NA dal conteggio può essere utile per un calcolo condizionato, ma nasconderebbe il problema se non dichiarassimo il numero eliminato.

2. Rispondere a due domande diverse

Calcoliamo la quota di Spiky accertati fra tutti gli individui e la quota di Spiky fra quelli classificati. Entrambe sono corrette, ma rispondono a domande differenti e richiedono etichette diverse.

R · codice commentato
# na.rm consente il conteggio dei casi noti; non assegna una categoria agli ignoti.
n_spiky <- sum(incompleti$morfotipo == "Spiky", na.rm = TRUE)
n_totale <- nrow(incompleti)
n_noti <- sum(noti)
quote <- c(sul_totale = n_spiky / n_totale,
           fra_classificati = n_spiky / n_noti)
print(100 * quote)
stopifnot(n_noti + sum(!noti) == n_totale)
Risultato dell’esecuzione
sul_totale fra_classificati 
         50.0000          51.9481

Lettura del risultato

L’argomento na.rm evita che una somma diventi NA; non recupera le etichette perdute. La seconda percentuale descrive i classificati e si estende agli altri solo con ipotesi sul meccanismo della mancata classificazione.

3. Delimitare ciò che non sappiamo

Senza ipotesi aggiuntive possiamo assegnare tutti gli ignoti prima all’altro morfotipo e poi a Spiky. Otteniamo limiti logici per la quota di Spiky nell’intero archivio, non un intervallo di confidenza.

R · codice commentato
n_ignoti <- sum(!noti)
# Gli estremi corrispondono a nessun ignoto Spiky oppure a tutti gli ignoti Spiky.
limiti <- c(minimo = n_spiky / n_totale,
            massimo = (n_spiky + n_ignoti) / n_totale)
print(100 * limiti)
quota_originale <- mean(f$morfotipo == "Spiky")
print(quota_originale)
stopifnot(quota_originale >= limiti[1], quota_originale <= limiti[2])
Risultato dell’esecuzione
minimo massimo 
  50.00   53.75 
[1] 0.5

Lettura del risultato

Nel laboratorio conosciamo il file completo e possiamo verificare i limiti. In una raccolta reale le etichette originali potrebbero essere irrecuperabili: i limiti resterebbero una descrizione dell’incertezza da informazione mancante.

Variante svolta

Ripetere il calcolo cancellando le etichette di sei Spiky, per mostrare l’effetto di una mancanza selettiva.

R · codice commentato
selettivi <- f$morfotipo
selettivi[head(which(selettivi == "Spiky"), 6)] <- NA_character_
tab_selettiva <- table(selettivi, useNA = "ifany")
print(tab_selettiva)
print(c(sul_totale = sum(selettivi == "Spiky", na.rm = TRUE) / length(selettivi),
        sui_noti = mean(selettivi[!is.na(selettivi)] == "Spiky")))
Risultato dell’esecuzione
selettivi
Rounded   Spiky    <NA> 
     80      74       6 
sul_totale   sui_noti 
  0.462500   0.480519

La quota fra classificati cambia quando la mancanza colpisce selettivamente una categoria. La sola esclusione degli NA non garantisce una composizione rappresentativa del campione iniziale.

Errore da riconoscere

Non trasformare NA nella categoria meno frequente e non interpretare na.rm = TRUE come una correzione del possibile errore di selezione.

Risposta alla domanda

La percentuale va accompagnata dal suo denominatore e dalla numerosità non classificata. Quando le etichette mancanti possono dipendere dal morfotipo, occorrono limiti o informazioni aggiuntive prima di estendere il risultato.
