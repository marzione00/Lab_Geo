Come costruire una tabella di frequenze e un istogramma che assegnino esattamente gli stessi individui alle classi?

Prima di iniziare

  • Dichiarare estremi, ampiezza e chiusura degli intervalli.

  • Verificare la corrispondenza fra cut e hist.

Prerequisiti. Istogrammi, frequenze, sequenze e operatori di confronto.

Dati e unità. Archivio didattico sintetico: 160 fossili, 80 Rounded e 80 Spiky. Diametri e spessori sono espressi in micrometri; ogni riga identifica un individuo.

Percorso dello svolgimento

  1. Definire le classi prima del conteggio
  2. Assegnare individui e controllare
  3. Disegnare e conservare la tabella

1. Definire le classi prima del conteggio

Scegliamo intervalli di mezzo micrometro che coprano tutte le misure. Gli estremi derivano dal campo dei dati, mentre l’ampiezza è una scelta didattica dichiarata e non un parametro stimato della popolazione.

R · codice commentato
f <- carica_dati("fossili_simulati.csv")
x <- f$diametro_tot_um
ampiezza <- .5
# Arrotondiamo verso l esterno per includere tutte le misure nei confini.
inferiore <- floor(min(x) / ampiezza) * ampiezza
superiore <- ceiling(max(x) / ampiezza) * ampiezza
confini <- seq(inferiore, superiore, by = ampiezza)
print(confini)
stopifnot(min(x) >= confini[1], max(x) <= tail(confini, 1))
Risultato dell’esecuzione
[1] 3.5 4.0 4.5 5.0 5.5 6.0 6.5 7.0 7.5 8.0 8.5 9.0

Lettura del risultato

Le classi ricoprono l’intero intervallo osservato senza sovrapporsi. Se aggiungessimo un valore oltre gli estremi dovremmo ricalcolare i confini, altrimenti alcune osservazioni resterebbero escluse.

2. Assegnare individui e controllare

Adottiamo intervalli aperti a sinistra e chiusi a destra, includendo anche il primo estremo. Usiamo gli stessi argomenti in cut e hist; le etichette dei fattori aiutano a rendere visibile la convenzione.

R · codice commentato
# right = TRUE chiude a destra; include.lowest include anche il minimo bordo.
classe <- cut(x, breaks = confini, right = TRUE, include.lowest = TRUE)
conteggi <- table(classe)
h <- hist(x, breaks = confini, right = TRUE, include.lowest = TRUE, plot = FALSE)
tab <- data.frame(classe = names(conteggi), n = as.integer(conteggi),
                  frequenza = as.integer(conteggi) / length(x))
print(tab)
stopifnot(!anyNA(classe), sum(conteggi) == length(x))
stopifnot(all(as.integer(conteggi) == h$counts))

Lettura del risultato

I conteggi coincidono perché confini e convenzioni coincidono. hist usa una piccola tolleranza numerica vicino ai bordi: quando misure e bordi differiscono soltanto per arrotondamenti informatici, occorre controllare esplicitamente l’assegnazione.

3. Disegnare e conservare la tabella

L’istogramma finale ha classi equiampie, quindi possiamo usare i conteggi come altezze. La tabella conserva anche le quote e viene esportata per consentire al lettore di verificare la figura.

R · codice commentato
plot(h, freq = TRUE, col = "#1D7890", border = "white",
     xlab = "Diametro totale (um)", ylab = "Fossili per classe (n)",
     main = "Classi dichiarate di 0,5 um")
write.csv(tab, percorso_risultati("frequenze_classi_05um.csv"), row.names = FALSE)
# Un esempio esatto sui bordi rende verificabile la convenzione degli intervalli.
casi_bordo <- c(0, .5, 1)
print(data.frame(valore = casi_bordo,
  classe = cut(casi_bordo, c(0, .5, 1), right = TRUE, include.lowest = TRUE)))

Variante svolta

Ripetere l’intera classificazione con ampiezza di un micrometro e verificare la conservazione degli individui.

confini_1 <- seq(floor(min(x)), ceiling(max(x)), by = 1)
classe_1 <- cut(x, confini_1, right = TRUE, include.lowest = TRUE)
t1 <- table(classe_1)
h1 <- hist(x, breaks = confini_1, right = TRUE, include.lowest = TRUE, plot = FALSE)
print(data.frame(classe = names(t1), n = as.integer(t1)))
stopifnot(sum(t1) == length(x), all(as.integer(t1) == h1$counts))

Errore da riconoscere

Non definire i bordi una volta nella tabella e un’altra nel grafico con una regola automatica. Non ignorare gli NA prodotti da cut: potrebbero segnalare misure fuori intervallo.

Risposta alla domanda

Confini e convenzione di chiusura fanno parte della definizione delle classi. Usarli in modo identico per tabella e grafico, controllando conteggi e bordi, rende il laboratorio riproducibile e impedisce esclusioni silenziose.
