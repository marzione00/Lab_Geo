1. Localizzare le posizioni

Un quantile campionario colloca una soglia nell’insieme ordinato. Per rendere il risultato riproducibile specifichiamo type = 7, la convenzione predefinita di R; con pochi dati altre convenzioni possono dare valori differenti.

R · codice commentato
f <- carica_dati("fossili_simulati.csv")
x <- f$diametro_tot_um
probabilita <- c(0, .25, .50, .75, 1)
# type = 7 rende esplicita la convenzione di interpolazione usata per i quantili.
q <- quantile(x, probs = probabilita, type = 7)
print(q)
iqr <- unname(q[4] - q[2])
print(c(IQR_um = iqr, IQR_funzione_um = IQR(x, type = 7)))
Risultato dell’esecuzione

3.67789 5.80623 6.42891 7.02834 8.62098 
         IQR_um IQR_funzione_um 
        1.22211         1.22211

Lettura del risultato

Il primo e il terzo quartile delimitano la fascia centrale secondo l’interpolazione scelta. Non promettono che esattamente il cinquanta per cento dei valori cada fra due soglie in ogni piccolo campione con ripetizioni.

2. Vedere centro e fascia centrale

Disegniamo gli individui lungo una scala comune e sovrapponiamo quartili e mediana. La fascia colorata riguarda la distribuzione delle osservazioni; non rappresenta l’incertezza statistica della mediana stimata.

R · codice commentato
plot(x, rep(1, length(x)), pch = 16, col = "#1D7890", yaxt = "n",
     ylim = c(.5, 1.5), xlab = "Diametro totale (um)", ylab = "",
     main = "Individui e metà centrale")
# Il segmento mostra Q1-Q3; la sua lunghezza e espressa in micrometri.
segments(q[2], 1.25, q[4], 1.25, lwd = 7, col = "#C57E42")
abline(v = q[3], lty = 2, col = "#7363AA")
text(c(q[2], q[4]), 1.38, labels = c("Q1", "Q3"))
print(c(sotto_Q1 = mean(x <= q[2]), sopra_Q3 = mean(x >= q[4])))
Risultato dell’esecuzione
sotto_Q1 sopra_Q3 
    0.25     0.25

Lettura del risultato

L’intervallo interquartile è la differenza Q3 meno Q1 e possiede l’unità delle misure. Due campioni possono avere lo stesso IQR e code molto differenti: i quartili non descrivono da soli tutti gli estremi.

3. Modificare una sola osservazione

Inseriamo un valore artificiale di 30 micrometri in una copia. La prova non è una procedura di pulizia: serve a confrontare la risposta degli indici quando cambia una sola osservazione.

R · codice commentato
alterato <- x
# La sostituzione artificiale serve a studiare sensibilita, non a correggere il file.
alterato[1] <- 30
descrivi <- function(v) c(media = mean(v), mediana = median(v),
                          sd = sd(v), IQR = IQR(v, type = 7))
confronto <- rbind(originale = descrivi(x), con_estremo = descrivi(alterato))
print(confronto)
print(confronto[2, ] - confronto[1, ])
Risultato dell’esecuzione
media mediana      sd     IQR
originale   6.35464 6.42891 1.00131 1.22211
con_estremo 6.49693 6.42891 2.11985 1.22211
   media  mediana       sd      IQR 
0.142287 0.000000 1.118538 0.000000

Lettura del risultato

Media e deviazione standard possono reagire molto alla distanza dell’estremo. Mediana e IQR dipendono soprattutto dalle posizioni centrali, ma possono comunque cambiare perché la sostituzione modifica l’ordinamento delle osservazioni.

La differenza è un effetto della definizione campionaria, non un errore aritmetico. Registrare la convenzione è particolarmente utile nei campioni piccoli e nei confronti fra software.

Errore da riconoscere

Non interpretare un valore fuori dalla fascia Q1–Q3 come un errore: circa metà della distribuzione può trovarsi fuori da quella fascia per definizione.

Risposta alla domanda

Quartili e IQR descrivono posizione e ampiezza della metà centrale con minore sensibilità agli estremi. Per una descrizione completa devono essere accompagnati da numerosità, unità e informazioni sulle code.
