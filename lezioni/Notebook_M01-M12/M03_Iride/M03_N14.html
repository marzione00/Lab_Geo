Boxplot con punti: centro, dispersione e numerosità

Che cosa aggiungono gli individui sovrapposti al boxplot nel confronto fra morfotipi?

  • Leggere scatola, mediana, baffi e valori oltre i baffi.

1. Riassumere prima di disegnare

Calcoliamo numerosità, mediana e IQR per gruppo. Il boxplot sintetizza questi aspetti, ma non mostra da solo quanti individui occupino una zona della distribuzione o se esistano concentrazioni interne.

R · codice commentato
f <- carica_dati("fossili_simulati.csv")
gruppi <- split(f$diametro_tot_um, f$morfotipo)
tab <- t(sapply(gruppi, function(x)
  c(n = length(x), mediana_um = median(x), IQR_um = IQR(x, type = 7))))
print(tab)
# boxplot.stats restituisce cerniere, baffi e osservazioni oltre i baffi.
dettagli <- lapply(gruppi, boxplot.stats)
print(lapply(dettagli, function(z) z$stats))

Lettura del risultato

Gli estremi della scatola di boxplot usano le cerniere di Tukey, che possono differire dai quartili interpolati type = 7 nei campioni piccoli. Specificare la funzione impiegata evita confronti apparentemente contraddittori.

2. Sovrapporre gli individui

Il jitter sposta leggermente i punti in orizzontale per ridurre la sovrapposizione, senza cambiare il diametro sull’asse verticale. Il seme rende ripetibile soltanto questa disposizione grafica.

R · codice commentato
set.seed(314)
# ylim include anche gli estremi: outline = FALSE non deve nascondere i punti aggiunti.
boxplot(diametro_tot_um ~ morfotipo, data = f, outline = FALSE, ylim = range(f$diametro_tot_um),
        col = c("#D5E9EE", "#F1DFCF"), ylab = "Diametro totale (um)",
        xlab = "Morfotipo", main = "Distribuzioni e singoli individui")
stripchart(diametro_tot_um ~ morfotipo, data = f, vertical = TRUE,
           method = "jitter", jitter = .13, add = TRUE,
           pch = 16, cex = .65, col = "#1D7890")
mtext(paste(paste(names(gruppi), lengths(gruppi), sep = ": n="), collapse = "; "), side = 3, cex = .8)

Lettura del risultato

outline = FALSE evita di disegnare due volte i punti oltre i baffi: tutti gli individui ricompaiono nello stripchart. Non è un’eliminazione dei dati e non modifica mediana, quartili o numerosità.

3. Interpretare i baffi

I baffi usuali si estendono fino alle osservazioni più estreme entro una distanza di una volta e mezzo l’ampiezza della scatola. Elenchiamo i punti segnalati dalla regola senza definirli automaticamente errori.

R · codice commentato
# La regola grafica segnala osservazioni da esaminare, senza cancellarle.
fuori_baffi <- lapply(dettagli, function(z) z$out)
print(fuori_baffi)
n_fuori <- lengths(fuori_baffi)
print(data.frame(morfotipo = names(n_fuori), oltre_baffi = n_fuori))
stopifnot(sum(lengths(gruppi)) == nrow(f))
print(range(f$diametro_tot_um))

Lettura del risultato

Un punto oltre il baffo è insolito secondo una regola descrittiva, non necessariamente scorretto. Il boxplot non fornisce qui intervalli di confidenza: la separazione delle scatole non è un test statistico.

Variante svolta

Ridurre Rounded a venti individui e verificare perché occorre indicare le numerosità.

R · codice commentato
idx <- c(head(which(f$morfotipo == "Rounded"), 20), which(f$morfotipo == "Spiky"))
ridotto <- f[idx, , drop = FALSE]
print(table(ridotto$morfotipo))
boxplot(diametro_tot_um ~ morfotipo, data = ridotto, varwidth = TRUE,
        col = c("#D5E9EE", "#F1DFCF"), ylab = "Diametro totale (um)",
        main = "Larghezza proporzionale alla radice di n")
stopifnot(nrow(ridotto) == 100)
Risultato dell’esecuzione
Rounded   Spiky 
     20      80

varwidth associa la larghezza alla radice della numerosità. È un aiuto visivo, ma un’etichetta con n resta più precisa; il sottoinsieme è costruito per il confronto e non è un nuovo campione casuale.

Errore da riconoscere

Non attribuire significato numerico allo spostamento orizzontale dei punti. Non eliminare automaticamente le osservazioni oltre i baffi e non leggere la scatola come intervallo di confidenza.

Risposta alla domanda

Il boxplot riassume posizioni e dispersione; i punti rendono visibili individui e concentrazioni. La combinazione è utile se si dichiarano numerosità, regola dei baffi e natura puramente grafica del jitter.
