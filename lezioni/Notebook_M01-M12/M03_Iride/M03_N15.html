1. Calcolare una quota sotto soglia

La cumulativa empirica in t conta gli individui con misura minore o uguale a t e divide per n. La funzione ecdf memorizza questa regola e può essere valutata per qualsiasi soglia.

R · codice commentato
f <- carica_dati("fossili_simulati.csv")
gruppi <- split(f$diametro_tot_um, f$morfotipo)
soglia <- 6
cumulate <- lapply(gruppi, ecdf)
# Il confronto <= include gli individui esattamente uguali alla soglia.
dirette <- sapply(gruppi, function(x) mean(x <= soglia))
tramite_funzione <- sapply(cumulate, function(Fn) Fn(soglia))
print(data.frame(morfotipo = names(dirette), quota_fino_a_6_um = dirette))
stopifnot(max(abs(dirette - tramite_funzione)) < 1e-12)
Risultato dell’esecuzione
morfotipo quota_fino_a_6_um
Rounded   Rounded            0.4125
Spiky       Spiky            0.2375

Lettura del risultato

La quota riguarda il campione e una soglia espressa nelle stesse unità dei diametri. Non richiede classi; la funzione aumenta soltanto quando la soglia attraversa una misura osservata.

2. Confrontare le curve

Disegniamo le due cumulative su assi comuni. A una stessa soglia, la curva più alta indica una quota maggiore di individui piccoli; per interpretare una posizione orizzontale conviene invece fissare una probabilità.

R · codice commentato
limiti <- range(f$diametro_tot_um)
# Assi comuni consentono di leggere differenze verticali alla stessa soglia.
plot(cumulate[[1]], xlim = limiti, verticals = TRUE, do.points = FALSE,
     col = "#1D7890", lwd = 2, xlab = "Diametro totale (um)",
     ylab = "Quota con diametro <= soglia", main = "Cumulative empiriche")
lines(cumulate[[2]], verticals = TRUE, do.points = FALSE, col = "#C57E42", lwd = 2)
abline(v = soglia, lty = 2, col = "gray40")
legend("bottomright", names(cumulate), col = c("#1D7890", "#C57E42"), lwd = 2, bty = "n")

Lettura del risultato

Le curve possono incrociarsi: in quel caso l’ordine fra gruppi dipende dalla soglia. Una differenza visiva delle cumulative è descrittiva e non costituisce da sola una valutazione inferenziale.

3. Controllare salti e valori ripetuti

Un esempio breve rende visibile il significato di minore o uguale. Quando due misure coincidono, la cumulativa compie un salto pari a due diviso n; non sempre ogni salto vale uno diviso n.

R · codice commentato
esempio <- c(4, 5, 5, 7)
# Le due misure uguali a cinque producono un unico salto di ampiezza 2/4.
Fpiccola <- ecdf(esempio)
t <- c(4.9, 5, 5.1)
print(data.frame(soglia = t, cumulativa = Fpiccola(t)))
print(c(strettamente_sotto_5 = mean(esempio < 5), fino_a_5 = mean(esempio <= 5)))
stopifnot(Fpiccola(5) == 3 / 4)
print(quantile(esempio, .5, type = 1))

Variante svolta

Alzare la soglia a 6,5 micrometri e confrontare l’aumento della quota nei due gruppi.

R · codice commentato
nuova_soglia <- 6.5
nuove <- sapply(cumulate, function(Fn) Fn(nuova_soglia))
incremento <- nuove - dirette
print(data.frame(prima = dirette, dopo = nuove, quota_fra_soglie = incremento))
controllo <- sapply(gruppi, function(x) mean(x > soglia & x <= nuova_soglia))
stopifnot(max(abs(incremento - controllo)) < 1e-12)
Risultato dell’esecuzione

Rounded 0.4125 0.6375            0.225
Spiky   0.2375 0.4375            0.200

La differenza fra cumulative conta l’intervallo aperto a sinistra e chiuso a destra. Cambiare una disuguaglianza può alterare il risultato quando esistono misure esattamente sulle soglie.

Errore da riconoscere

Non leggere la cumulativa come densità: la sua altezza è una quota accumulata, non la frequenza locale. Non confondere una differenza verticale con una differenza di diametro.

Risposta alla domanda

La cumulativa risponde direttamente a domande su soglie e intervalli senza scegliere classi. Occorre dichiarare le disuguaglianze, soprattutto quando misure arrotondate o ripetute producono salti consistenti.
