Come consegnare una figura autonoma, con unità, origine dei dati e didascalia coerente con i calcoli?

Prima di iniziare

  • Riutilizzare una funzione di disegno per anteprima ed esportazione.

Prerequisiti. Scatterplot, funzioni e percorsi dei risultati.

Dati e unità. Archivio didattico sintetico: 160 fossili, 80 Rounded e 80 Spiky. Diametri e spessori sono espressi in micrometri; ogni riga identifica un individuo.

Preparazione del progetto e seme casuale

Aprire il progetto GeoStat_Lab_Notebooks.Rproj e poi il file Rmd. Questo blocco trova le cartelle dei dati e dei risultati senza usare percorsi personali.

1. Preparare il disegno riutilizzabile

Una funzione raccoglie tutte le decisioni grafiche. La stessa funzione verrà richiamata sul dispositivo di anteprima e nel PDF, evitando che un’etichetta corretta in una versione resti sbagliata nell’altra.

R · codice commentato
f <- carica_dati("fossili_simulati.csv")
# Una sola funzione mantiene coerenti anteprima e file esportato.
disegna <- function(d) {
  g <- factor(d$morfotipo)
  palette <- c("#1D7890", "#C57E42")
  plot(d$diametro_tot_um, d$diametro_int_um, pch = c(16, 17)[g],
       col = palette[g], xlab = "Diametro totale (um)",
       ylab = "Diametro interno (um)", main = "Geometria dei fossili sintetici")
  legend("topleft", levels(g), col = palette, pch = c(16, 17), bty = "n")
}
disegna(f)

Lettura del risultato

La funzione riceve la tabella da rappresentare, senza leggerla di nuovo né modificare il file originale. Colore e simbolo comunicano la stessa categoria, rendendo la figura leggibile anche in stampa monocromatica.

2. Aprire e chiudere il dispositivo

Il PDF conserva linee e testo come elementi vettoriali. La funzione di esportazione usa on.exit per chiudere il dispositivo anche se il disegno genera un errore; il file viene scritto soltanto nella cartella dei risultati.

R · codice commentato
salva_pdf <- function(d, nome) {
  destinazione <- percorso_risultati(nome)
  grDevices::pdf(destinazione, width = 7, height = 5, useDingbats = FALSE)
  # La chiusura del dispositivo e garantita anche se il disegno si interrompe.
  on.exit(grDevices::dev.off(), add = TRUE)
  disegna(d)
  invisible(destinazione)
}
file_figura <- salva_pdf(f, "diametri_fossili.pdf")
stopifnot(file.exists(file_figura), file.info(file_figura)$size > 0)
print(data.frame(file = basename(file_figura), bytes = file.info(file_figura)$size))

Lettura del risultato

Le dimensioni sono in pollici e determinano lo spazio disponibile per assi e legenda. Un file esistente e non vuoto conferma la scrittura; non dimostra da solo che le etichette siano ben posizionate, perciò va anche osservata l’anteprima.

3. Scrivere una didascalia autonoma

La didascalia identifica unità osservativa, numerosità e natura sintetica dei dati. Specifica inoltre che la figura mostra un’associazione descrittiva: il lettore deve capirne il significato anche senza il testo del notebook.

R · codice commentato
n_gruppi <- table(f$morfotipo)
        # Le numerosita della didascalia sono ricavate dai dati utilizzati nella figura.
        dettagli <- paste(paste(names(n_gruppi), as.integer(n_gruppi), sep = " n="), collapse = "; ")
        didascalia <- sprintf(paste("Diametro interno in funzione del diametro totale per %d fossili sintetici.",
          "Ogni punto rappresenta un individuo; entrambe le misure sono in micrometri.",
          "Colori e simboli distinguono i morfotipi (%s). Il grafico descrive il campione."), nrow(f), dettagli)
        file_didascalia <- percorso_risultati("diametri_fossili_didascalia.txt")
        writeLines(didascalia, file_didascalia, useBytes = TRUE)
        cat(readLines(file_didascalia, warn = FALSE), "
")
Risultato dell’esecuzione
Diametro interno in funzione del diametro totale per 160 fossili sintetici. Ogni punto rappresenta un individuo; entrambe le misure sono in micrometri. Colori e simboli distinguono i morfotipi (Rounded n=80; Spiky n=80). Il grafico descrive il campione.

Lettura del risultato

La didascalia non deve promettere una relazione causale o una significatività non analizzata. Poiché le numerosità sono ricavate dalla tabella, una nuova esecuzione con un sottoinsieme può aggiornare automaticamente la descrizione.

Variante svolta

Esportare soltanto Rounded con un nome diverso e produrre una didascalia specifica.

rounded <- f[f$morfotipo == "Rounded", , drop = FALSE]
        secondo_pdf <- salva_pdf(rounded, "diametri_rounded.pdf")

Risultato dell’esecuzione
Diametri di 80 fossili Rounded sintetici; un punto per individuo; misure in micrometri.

Il nome distinto conserva entrambe le figure. La nuova didascalia non deve riportare la numerosità totale o menzionare un confronto con Spiky che non è più visibile.

Errore da riconoscere

Non dimenticare dev.off dopo un’esportazione e non usare una didascalia copiata senza aggiornare numerosità e categorie. Non sovrascrivere i dati per salvare i risultati.

Risposta alla domanda

Figura e didascalia formano una consegna verificabile quando condividono dati, unità e categorie. La funzione di disegno evita divergenze fra anteprima e file; percorsi separati conservano l’archivio originale.
