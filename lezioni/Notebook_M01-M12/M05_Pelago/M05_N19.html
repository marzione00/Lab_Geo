Reinserimento e bootstrap enumerato

M05_N19 · Pelago · soluzione eseguita e commentata

Possiamo elencare tutte le repliche bootstrap di quattro dati e verificarne esattamente la distribuzione?

Prima di iniziare

  • Enumerare sequenze con reinserimento.

  • Distinguere distribuzione bootstrap e semplice permutazione.

Prerequisiti. Vettori, indicizzazione, media, varianza e grafici di base in R.

Dati e unità. Quattro valori didattici, 2, 4, 8 e 10, in unità convenzionali. Le 4⁴ sequenze ordinate hanno la stessa probabilità.

1. Enumerare le sequenze di indici

Ogni posizione della replica può contenere uno dei quattro indici originali. Il prodotto cartesiano delle scelte genera tutte le sequenze ordinate; alcune producono gli stessi conteggi e la stessa media, ma devono mantenere la loro molteplicità probabilistica.

R · codice commentato
x <- c(2, 4, 8, 10)
n <- length(x)
sequenze <- as.matrix(expand.grid(rep(list(seq_len(n)), n)))
medie <- apply(sequenze, 1, function(i) mean(x[i]))
stopifnot(nrow(sequenze) == n^n)
print(c(sequenze = nrow(sequenze), medie_distinte = length(unique(medie))))
print(head(data.frame(sequenze, media = medie)))

2. Calcolare media e varianza della distribuzione esatta

La distribuzione enumerata è completa, quindi la sua varianza usa la media degli scarti quadratici e non la correzione di var. Per la media bootstrap il valore teorico è (n−1)s²/n², con s² calcolata sui dati originali.

R · codice commentato
centro <- mean(medie)
var_esatta <- mean((medie - centro)^2)
var_formula <- (n - 1) * var(x) / n^2
stopifnot(isTRUE(all.equal(centro, mean(x))))
stopifnot(isTRUE(all.equal(var_esatta, var_formula)))
distribuzione <- prop.table(table(medie))
print(data.frame(media = as.numeric(names(distribuzione)),
                 probabilita = as.numeric(distribuzione)))
print(c(media_boot = centro, varianza_boot = var_esatta))

3. Confrontare enumerazione e Monte Carlo

La simulazione sceglie soltanto una parte delle sequenze, ammettendo ripetizioni anche fra repliche. Possiamo confrontarne i risultati con il riferimento enumerato: ogni differenza in questo confronto è numerica, non un dubbio su quale distribuzione stiamo calcolando.

R · codice commentato
set.seed(519)
B <- 2000
simulate <- replicate(B, mean(sample(x, n, replace = TRUE)))
print(data.frame(metodo = c("Enumerato", "Monte Carlo"),
  media = c(centro, mean(simulate)),
  SD = c(sqrt(var_esatta), sd(simulate))))
barplot(distribuzione, col = "#95BDD0", border = NA,
        xlab = "Media della replica (u.c.)", ylab = "Probabilita",
        main = "Distribuzione bootstrap esatta")
Risultato dell’esecuzione

1   Enumerato 6.00000 1.58114

Lettura del risultato

Aumentare B migliora l’approssimazione della distribuzione enumerata. Non rende più rappresentativi i quattro valori iniziali e non assicura la copertura di un intervallo sulla popolazione.

Variante svolta

Ripetere l’estrazione di tutti i dati senza reinserimento e verificare la varianza delle medie.

R · codice commentato
senza <- replicate(B, mean(sample(x, n, replace = FALSE)))
print(c(media_senza = mean(senza), SD_senza = sd(senza)))
stopifnot(all(senza == mean(x)))
print(quantile(medie, c(0.025, 0.975)))
Risultato dell’esecuzione

Senza reinserimento si permutano sempre gli stessi quattro valori: la media non varia. L’intervallo percentile della distribuzione bootstrap è invece ottenuto da selezioni con reinserimento.

Errore da riconoscere

Non trattare le combinazioni non ordinate come equiprobabili: una composizione con valori distinti può essere generata da più sequenze di una composizione con quattro valori uguali.

Risposta alla domanda

Il piccolo esempio rende controllabili le probabilità del bootstrap. L’enumerazione elimina l’errore Monte Carlo ma resta condizionata al campione osservato.
