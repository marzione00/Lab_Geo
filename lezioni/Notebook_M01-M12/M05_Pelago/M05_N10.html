1. Assegnare massa alle osservazioni

La distribuzione empirica assegna massa 1/n a ciascuna osservazione, non a ciascun valore distinto. Quando una misura compare più volte, la sua probabilità empirica è la somma delle masse corrispondenti. Questo passaggio determina il modello usato dal bootstrap non parametrico.

R · codice commentato
x <- c(2, 2, 3, 4, 4, 9)
n <- length(x)
frequenze <- table(x)
valori <- as.numeric(names(frequenze))
probabilita <- as.numeric(frequenze) / n
print(data.frame(valore = valori, frequenza = as.integer(frequenze),
                 probabilita_empirica = probabilita))
stopifnot(abs(sum(probabilita) - 1) < 1e-12)
Risultato dell’esecuzione
valore frequenza probabilita_empirica
1      2         2             0.333333
2      3         1             0.166667
3      4         2             0.333333
4      9         1             0.166667

Lettura del risultato

I valori due e quattro ricevono più massa perché sono stati osservati due volte. Rimuovere i duplicati cambierebbe la distribuzione su cui si fonda il ricampionamento.

2. Costruire la funzione di ripartizione

La funzione empirica F_n(t) è la proporzione di osservazioni minori o uguali a t. È una funzione a gradini: un salto più alto segnala più osservazioni nello stesso punto. Verifichiamo alcuni valori con un conteggio diretto.

R · codice commentato
Fn <- ecdf(x)
soglie <- c(1, 2, 3.5, 4, 9, 10)
diretto <- sapply(soglie, function(t) mean(x <= t))
print(data.frame(soglia = soglie, Fn = Fn(soglie), conteggio = diretto))
stopifnot(isTRUE(all.equal(Fn(soglie), diretto)))
plot(Fn, verticals = TRUE, do.points = TRUE, col = "#27647B",
     main = "Distribuzione empirica", xlab = "Misura (u.c.)",
     ylab = "Proporzione minore o uguale")

Sotto il minimo osservato la funzione vale zero e dal massimo osservato in poi vale uno. Queste proprietà descrivono il campione, non dimostrano che la popolazione abbia gli stessi estremi.

3. Ricampionare dalla distribuzione osservata

Ricampionando con reinserimento scegliamo ogni volta uno degli indici originali. Possiamo ottenere molteplicità diverse, ma mai un valore individuale assente dal campione. Una media bootstrap può invece assumere combinazioni non presenti fra le misure originali.

R · codice commentato
set.seed(510)
B <- 1500
repliche <- replicate(B, sample(x, size = n, replace = TRUE))
medie <- colMeans(repliche)
print(c(min_dato_boot = min(repliche), max_dato_boot = max(repliche),
        media_originale = mean(x), media_boot = mean(medie)))
stopifnot(all(as.vector(repliche) %in% x))
print(c(media_empirica_pesata = sum(valori * probabilita),
        media_valori_distinti = mean(unique(x))))
Risultato dell’esecuzione

Lettura del risultato

La media dei valori distinti usa pesi diversi e risponde a un’altra domanda. Il bootstrap conserva i valori osservati ma cambia quali e quante volte entrano in una replica.

Variante svolta

Calcolare la probabilità empirica di osservare un valore maggiore di quattro, e confrontarla con il ricampionamento.

R · codice commentato
p_empirica <- mean(x > 4)
p_da_Fn <- 1 - Fn(4)
p_simulata <- mean(repliche > 4)
print(c(empirica = p_empirica, da_ripartizione = p_da_Fn, simulata = p_simulata))
stopifnot(isTRUE(all.equal(p_empirica, p_da_Fn)))
Risultato dell’esecuzione
empirica da_ripartizione        simulata 
       0.166667        0.166667        0.168889

La frequenza simulata oscilla attorno alla probabilità empirica. Non fornisce una nuova osservazione delle code della popolazione: ripete l’informazione contenuta nei sei dati.

Errore da riconoscere

Non eliminare valori ripetuti prima di costruire la distribuzione empirica e non usare il bootstrap per sostenere che estremi mai osservati siano impossibili.

Risposta alla domanda

La distribuzione empirica conserva frequenze e supporto osservati. Il bootstrap studia una procedura condizionata a questa informazione e non sostituisce un nuovo campionamento.
