1. Definire due bersagli distinti

La media usa tutte le distanze numeriche; la mediana identifica il centro in termini di ordine. Coincidono in alcune popolazioni, ma non definiscono lo stesso parametro in generale. Calcolarle entrambe è utile soltanto se manteniamo chiara questa differenza.

R · codice commentato
dati <- carica_dati("fossili_simulati.csv")
x <- dati$diametro_tot_um[dati$morfotipo == "Rounded"]
stopifnot(all(is.finite(x)), all(x > 0))
n <- length(x)
osservate <- c(media = mean(x), mediana = median(x))
print(c(n = n, osservate))
print(quantile(x, c(0, 0.25, 0.5, 0.75, 1)))

     0%     25%     50%     75%    100% 
3.85224 5.25265 6.26980 6.68588 8.24928

Lettura del risultato

La distanza fra i due indici descrive questo campione. Non autorizza a scegliere la statistica soltanto perché restituisce il valore preferito nella conclusione.

2. Usare le stesse repliche per entrambe le statistiche

Selezioniamo una volta gli indici di ogni replica e calcoliamo sia media sia mediana. Così le differenze osservate dipendono dalla statistica applicata agli stessi valori ricampionati. Il numero di repliche è identico e il seme è registrato.

R · codice commentato
set.seed(520)
B <- 2000
boot <- replicate(B, {
  z <- x[sample.int(n, n, replace = TRUE)]
  c(media = mean(z), mediana = median(z))
})
se <- apply(boot, 1, sd)
intervalli <- t(apply(boot, 1, quantile, probs = c(0.025, 0.975)))
print(data.frame(statistica = names(osservate), stima = osservate,
                 SE_boot = se, intervalli))
Risultato dell’esecuzione
statistica   stima  SE_boot   X2.5.  X97.5.
media        media 6.06363 0.109070 5.84992 6.27812
mediana    mediana 6.26980 0.111503 5.95989 6.42896

Lettura del risultato

La dispersione delle repliche riguarda due stimatori di parametri diversi. Un SE più piccolo non stabilisce da solo quale statistica risponda meglio alla domanda scientifica.

3. Leggere la forma delle distribuzioni bootstrap

Confrontiamo gli istogrammi usando lo stesso asse orizzontale. La mediana può produrre una distribuzione più discreta perché dipende da pochi valori ordinati vicini al centro. Questa caratteristica va distinta da una maggiore o minore precisione in generale.

R · codice commentato
limiti <- range(boot)
vecchio <- par(mfrow = c(1, 2))
hist(boot["media", ], breaks = 25, xlim = limiti, col = "#95BDD0",
     border = "white", ylab = "Frequenza", main = "Media", xlab = "Diametro centrale (um)")
hist(boot["mediana", ], breaks = 25, xlim = limiti, col = "#E7B977",
     border = "white", ylab = "Frequenza", main = "Mediana", xlab = "Diametro centrale (um)")
par(vecchio)
print(c(correlazione_repliche = cor(boot["media", ], boot["mediana", ])))
Risultato dell’esecuzione
correlazione_repliche 
             0.766769

Lettura del risultato

Le due statistiche sono correlate perché usano le stesse osservazioni. Le differenze di forma vanno lette insieme alle definizioni dei parametri e alla distribuzione dei dati.

Variante svolta

Aggiungere venti micrometri al valore massimo in una copia del vettore e ricalcolare gli indici.

R · codice commentato
alterato <- x
posizione <- which.max(alterato)
alterato[posizione] <- alterato[posizione] + 20
nuove <- c(media = mean(alterato), mediana = median(alterato))
print(data.frame(statistica = names(osservate), originale = osservate,
                 alterata = nuove, variazione = nuove - osservate))
stopifnot(isTRUE(all.equal(unname(nuove["media"] - osservate["media"]), 20 / n)))
Risultato dell’esecuzione
statistica originale alterata variazione
media        media   6.06363  6.31363       0.25
mediana    mediana   6.26980  6.26980       0.00

La media aumenta esattamente di venti diviso n; la mediana resta invariata perché non cambiano i valori centrali. È una prova di sensibilità controllata, non una giustificazione per correggere o eliminare valori reali.

Errore da riconoscere

Non confondere robustezza rispetto a un estremo con precisione universalmente maggiore. La scelta del parametro precede il confronto delle distribuzioni bootstrap.

Risposta alla domanda

Media e mediana rispondono a domande diverse sul centro. Il bootstrap ne descrive il comportamento condizionato ai dati, mentre la variante rende esplicita la sensibilità a un estremo.
