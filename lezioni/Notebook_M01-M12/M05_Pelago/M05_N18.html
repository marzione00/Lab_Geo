1. Definire una funzione che restituisce i risultati necessari

Una funzione rende confrontabili le simulazioni: dati, statistica e quantili restano invariati mentre cambiano seme e numero di repliche. Registriamo queste scelte insieme ai risultati, invece di conservare soltanto un intervallo privo di provenienza.

R · codice commentato
dati <- carica_dati("fossili_simulati.csv")
x <- dati$diametro_tot_um[dati$morfotipo == "Rounded"]
stopifnot(all(is.finite(x)))
analizza_boot <- function(B, seme) {
  set.seed(seme)
  z <- replicate(B, mean(sample(x, length(x), TRUE)))
  q <- quantile(z, c(0.025, 0.975), names = FALSE)
  data.frame(B = B, seme = seme, SE = sd(z), inferiore = q[1], superiore = q[2])
}

Lettura del risultato

La funzione stima lo stesso bersaglio in ogni chiamata. L’eventuale differenza fra le righe dipende dal ricampionamento numerico, perché il campione osservato non è cambiato.

2. Confrontare più semi e più valori di B

Usiamo sei semi per ciascuna numerosità di simulazione. La dispersione degli estremi fra semi descrive la stabilità numerica della procedura per questo campione. Sei ripetizioni forniscono una diagnosi didattica, non una misura molto precisa dell’errore Monte Carlo.

R · codice commentato
piano <- expand.grid(B = c(1000, 3000), seme = 518:523)
risultati <- do.call(rbind, lapply(seq_len(nrow(piano)), function(i)
  analizza_boot(piano$B[i], piano$seme[i])))
stabilita <- aggregate(cbind(SE, inferiore, superiore) ~ B,
                       data = risultati, FUN = sd)
print(risultati)
print(stabilita)
print(c(n_fossili = length(x), SE_classico = sd(x) / sqrt(length(x))))

Salviamo una tabella leggibile e un oggetto R che contiene dati di configurazione. Il percorso dedicato al notebook evita di sovrascrivere i dati originali. Rileggiamo i file per controllare che ciò che è stato scritto corrisponda agli oggetti analizzati.

Stesso algoritmo, stessi dati, stesso seme e stesso ambiente rendono riproducibile il calcolo. La riproducibilità non è una prova che il disegno di campionamento sia corretto.

Errore da riconoscere

Non presentare un B elevato come aumento della numerosità scientifica. Restano ottanta fossili, qualunque sia il numero di ricampionamenti.

Risposta alla domanda

La precisione numerica si controlla registrando semi, B e risultati. L’incertezza legata al campione richiede dati informativi e un disegno adeguato.
