1. Costruire dati e riferimento nullo

Usiamo un esempio costruito per separare i dati osservati dal modello di riassegnazione. Le due popolazioni generatrici hanno la stessa varianza e differiscono per posizione. La distribuzione nulla è ottenuta riassegnando le etichette ai valori osservati, non simulando nuovamente le popolazioni generatrici.

R · codice commentato
set.seed(605)
a <- rnorm(20, mean = 5, sd = 1)
b <- rnorm(25, mean = 5.6, sd = 1)
x <- c(a, b)
osservato <- mean(b) - mean(a)
B <- 2500
nulli <- replicate(B, {
  i <- sample.int(length(x), length(a), FALSE)
  mean(x[-i]) - mean(x[i])
})
print(c(differenza_B_A = osservato, nA = length(a), nB = length(b)))
Risultato dell’esecuzione
differenza_B_A             nA             nB 
       0.74035       20.00000       25.00000

Lettura del risultato

Lo spostamento impostato nel generatore e la differenza osservata non devono coincidere. Il campionamento produce variabilità anche quando il modello generatore è noto.

2. Disegnare soglie simmetriche

Per una statistica bilaterale basata sul valore assoluto, le soglie sono meno e più il valore assoluto osservato. Mostriamo una linea per il contrasto effettivamente osservato e segnaliamo entrambe le regioni estreme con i punti della simulazione.

R · codice commentato
soglia <- abs(osservato)
estremi <- abs(nulli) >= soglia
dominio <- range(c(nulli, -soglia, soglia))
hist(nulli, breaks = 35, xlim = dominio, col = "#C9DFE8",
     border = "white", ylab = "Frequenza", xlab = "Contrasto B - A sotto la nulla (u.c.)",
     main = "Due code per un confronto bilaterale")
abline(v = c(-soglia, soglia), col = "#A33B31", lty = 2, lwd = 2)
rug(nulli[estremi], col = "#A33B31")
abline(v = osservato, col = "#222222", lwd = 2)

Lettura del risultato

Le soglie dipendono dalla statistica osservata. Il numero di barre, il colore e la larghezza degli intervalli grafici non devono entrare nel calcolo del p-value.

3. Verificare il conteggio indipendentemente dal grafico

Contiamo le repliche direttamente dal vettore, includendo l’uguaglianza alla soglia. Il grafico illustra il criterio, mentre il vettore conserva i valori necessari per un conteggio preciso. Separiamo le due code per documentare il risultato.

R · codice commentato
sinistra <- sum(nulli <= -soglia)
destra <- sum(nulli >= soglia)
k <- sum(estremi)
p_mc <- (k + 1) / (B + 1)
print(c(coda_sinistra = sinistra, coda_destra = destra,
        totale_estremi = k, p_bilaterale = p_mc))
stopifnot(soglia > 0, sinistra + destra == k)
Risultato dell’esecuzione
coda_sinistra    coda_destra totale_estremi   p_bilaterale 
    31.0000000     25.0000000     56.0000000      0.0227909

Lettura del risultato

Le due code non devono contenere esattamente lo stesso numero di repliche in una simulazione finita. Il p-value non è la probabilità che la nulla sia vera dopo aver osservato i dati.

Variante svolta

Calcolare una coda destra per un’alternativa B maggiore di A definita prima dell’esperimento.

R · codice commentato
k_destra_osservata <- sum(nulli >= osservato)
p_destra <- (k_destra_osservata + 1) / (B + 1)
print(data.frame(alternativa = c("B diverso da A", "B maggiore di A"),
  p_MC = c(p_mc, p_destra)))
print(c(contrasto_osservato = osservato))
Risultato dell’esecuzione
alternativa      p_MC
1  B diverso da A 0.0227909
2 B maggiore di A 0.0103958
contrasto_osservato 
            0.74035

La soglia unilaterale è il contrasto con il suo segno, non il suo valore assoluto. Il confronto mostra come l’alternativa determina la regione estrema; non autorizza a sceglierla dopo i risultati.

Errore da riconoscere

Non stimare il p-value contando visivamente le barre oltre una linea. Usare i valori delle repliche e una regola di coda definita in anticipo.
