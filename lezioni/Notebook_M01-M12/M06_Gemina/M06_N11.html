1. Preparare una tabella di coppie complete

Un grafico appaiato richiede che ogni segmento colleghi la stessa unità. Conserviamo gli identificativi, controlliamo l’unicità ed escludiamo soltanto coppie incomplete dichiarandone il numero. La differenza con segno sarà usata sia per il colore sia per il riepilogo.

R · codice commentato
dati <- carica_dati("misure_appaiate_simulate.csv")
stopifnot(!anyDuplicated(dati$id))
utilizzabili <- complete.cases(dati[c("prima", "dopo")])
coppie <- dati[utilizzabili, ]
coppie$differenza <- coppie$dopo - coppie$prima
stopifnot(all(is.finite(coppie$differenza)))
print(c(coppie_totali = nrow(dati), coppie_usate = nrow(coppie)))
print(table(verso = sign(coppie$differenza)))

Lettura del risultato

Il conteggio per segno distingue aumenti, diminuzioni ed eventuali assenze di cambiamento. La media da sola potrebbe nascondere differenze individuali di verso opposto.

2. Collegare le misure della stessa unità

L’asse orizzontale identifica le due occasioni di misura, mentre quello verticale conserva la scala originale. Un segmento crescente indica un aumento. Usiamo una trasparenza moderata per rendere visibili le sovrapposizioni senza spostare artificialmente i valori.

R · codice commentato
colori <- ifelse(coppie$differenza >= 0, "#27647B", "#A33B31")
limiti <- range(c(coppie$prima, coppie$dopo))
plot(c(1, 2), limiti, type = "n", xaxt = "n",
     xlab = "Occasione", ylab = "Misura (u.c.)", main = "Ogni segmento e una coppia")
axis(1, at = c(1, 2), labels = c("Prima", "Dopo"))
segments(1, coppie$prima, 2, coppie$dopo,
         col = grDevices::adjustcolor(colori, alpha.f = 0.65))
points(rep(1, nrow(coppie)), coppie$prima, pch = 16, col = colori)
points(rep(2, nrow(coppie)), coppie$dopo, pch = 16, col = colori)

Lettura del risultato

Il grafico distingue eterogeneità dei livelli iniziali e direzione dei cambiamenti. Una nube molto dispersa nei livelli può comunque mostrare differenze entro coppia piuttosto regolari.

3. Disegnare direttamente le differenze

Per leggere la grandezza del cambiamento senza essere distratti dai livelli iniziali, rappresentiamo una differenza per identificativo. Ordiniamo soltanto la visualizzazione, lasciando intatta la tabella delle coppie. La linea a zero separa aumenti e diminuzioni.

R · codice commentato
ordine <- order(coppie$differenza)
dotchart(coppie$differenza[ordine], labels = coppie$id[ordine],
         xlab = "Dopo - prima (u.c.)", main = "Cambiamenti individuali",
         color = colori[ordine])
abline(v = 0, lty = 2)
abline(v = mean(coppie$differenza), col = "#222222", lwd = 2)
print(c(media_cambiamento = mean(coppie$differenza),
        SD_cambiamento = sd(coppie$differenza)))
Risultato dell’esecuzione
media_cambiamento    SD_cambiamento 
        0.0357298         0.0306574

Lettura del risultato

La distribuzione delle differenze è il dato centrale per un’analisi appaiata della media. La linea della media riassume la posizione ma non sostituisce l’osservazione dei singoli cambiamenti.

Variante svolta

Ordinare le coppie per valore iniziale e verificare che il cambiamento medio resti invariato.

R · codice commentato
ordinate <- coppie[order(coppie$prima), ]
media_ordinata <- mean(ordinate$dopo - ordinate$prima)
stopifnot(isTRUE(all.equal(media_ordinata, mean(coppie$differenza))))
print(head(ordinate[c("id", "prima", "dopo", "differenza")]))
print(c(media_ordinata = media_ordinata))

Errore da riconoscere

Due boxplot affiancati non mostrano quali misure appartengono alla stessa unità. Quando l’abbinamento conta, aggiungere segmenti o mostrare le differenze.

Risposta alla domanda

I segmenti rendono leggibile il disegno appaiato. Il grafico delle differenze collega direttamente i cambiamenti individuali alla quantità che verrà stimata.
