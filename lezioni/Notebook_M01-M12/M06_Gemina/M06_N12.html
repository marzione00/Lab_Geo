Il test appaiato è un test sulle differenze

M06_N12 · Gemina · soluzione eseguita e commentata

Come si ricostruiscono test t e intervallo per il cambiamento medio usando un solo vettore di differenze?

Sorgente R MarkdownCome eseguire il notebook

Prima di iniziare

  • Calcolare la media e il SE delle differenze.

  • Verificare l’equivalenza fra test a un campione e t.test appaiato.

Prerequisiti. Vettori, indicizzazione, media, varianza e grafici di base in R.

Dati e unità. Ventiquattro coppie sintetiche prima/dopo in unità convenzionali. Consideriamo indipendenti le coppie e, per l’esattezza finita del test, normali le differenze.

Percorso dello svolgimento

  1. Trasformare ogni coppia in un cambiamento
  2. Ricostruire la formula di Student
  3. Verificare le due formulazioni in R

1. Trasformare ogni coppia in un cambiamento

Sottraiamo prima da dopo soltanto sulle stesse coppie complete. Il vettore d contiene un’osservazione per unità indipendente. L’ipotesi nulla riguarda la media di questi cambiamenti; non richiede che le distribuzioni marginali di prima e dopo abbiano la stessa varianza.

R · codice commentato
dati <- carica_dati("misure_appaiate_simulate.csv")
stopifnot(!anyDuplicated(dati$id))
coppie <- dati[complete.cases(dati[c("prima", "dopo")]), ]
d <- coppie$dopo - coppie$prima
n <- length(d)
stopifnot(n > 1, all(is.finite(d)))
media_d <- mean(d)
se_d <- sd(d) / sqrt(n)
print(c(coppie = n, media_differenza = media_d, SE_differenza = se_d))
Risultato dell’esecuzione
coppie media_differenza    SE_differenza 
     24.00000000       0.03572978       0.00625791

Lettura del risultato

La dispersione di d, e non la dispersione separata delle due colonne, determina il SE appaiato. La numerosità è il numero di coppie utilizzabili.

2. Ricostruire la formula di Student

Per la nulla di cambiamento medio zero, t è la media delle differenze divisa per il suo SE. I gradi di libertà sono n−1. L’intervallo bilaterale usa la stessa distribuzione di riferimento e conserva l’unità originale delle misure.

R · codice commentato
delta0 <- 0
df <- n - 1
t_osservato <- (media_d - delta0) / se_d
p <- 2 * pt(-abs(t_osservato), df = df)
margine <- qt(0.975, df) * se_d
intervallo <- media_d + c(-1, 1) * margine
print(c(t = t_osservato, df = df, p_bilaterale = p))
print(c(inferiore = intervallo[1], superiore = intervallo[2]))
Risultato dell’esecuzione
t           df p_bilaterale 
 5.70954e+00  2.30000e+01  8.17245e-06 
inferiore superiore 
0.0227843 0.0486753

Lettura del risultato

Un intervallo che non comprende zero segnala incompatibilità con cambiamento medio nullo secondo questo metodo. Non implica che tutte le unità cambino nello stesso verso.

3. Verificare le due formulazioni in R

La formulazione appaiata calcola internamente le differenze nell’ordine degli argomenti. Confrontiamo t.test(d) con t.test(dopo, prima, paired = TRUE), mantenendo identiche coppie, livello e alternativa. I risultati devono coincidere entro la precisione numerica.

R · codice commentato
un_campione <- t.test(d, mu = delta0)
appaiato <- t.test(coppie$dopo, coppie$prima, paired = TRUE, mu = delta0)
stopifnot(isTRUE(all.equal(un_campione$p.value, appaiato$p.value)))
stopifnot(isTRUE(all.equal(p, appaiato$p.value)))
stopifnot(isTRUE(all.equal(as.numeric(appaiato$conf.int), intervallo)))
print(appaiato)
qqnorm(d, main = "Forma delle differenze", ylab = "Dopo - prima (u.c.)")
qqline(d, col = "#A33B31", lwd = 2)

Lettura del risultato

Variante svolta

Confrontare il cambiamento medio con 0,02 unità convenzionali, valore didattico fissato come riferimento.

R · codice commentato
riferimento <- 0.02
t_riferimento <- (media_d - riferimento) / se_d
p_riferimento <- 2 * pt(-abs(t_riferimento), df)
verifica <- t.test(d, mu = riferimento)
print(c(riferimento = riferimento, t = t_riferimento, p = p_riferimento))
stopifnot(isTRUE(all.equal(p_riferimento, verifica$p.value)))
Risultato dell’esecuzione
riferimento           t           p 
  0.0200000   2.5135847   0.0194033

Cambiare la nulla modifica il contrasto standardizzato e il p-value, ma non la stima del cambiamento medio. Il valore di riferimento richiede una motivazione scientifica in un’indagine reale.

Errore da riconoscere

Non richiedere normalità delle due colonne separatamente come condizione decisiva del test appaiato. Esaminare le differenze e il disegno delle coppie.

Risposta alla domanda

Il test appaiato è un test a un campione sulle differenze. Unità, segno, coppie complete e ipotesi devono essere espliciti in ogni passaggio.
