1. Fissare statistica e ipotesi di scambiabilità

La statistica è la media di B meno la media di A. Una permutazione lascia fissi i valori e cambia quali ricevono ogni etichetta, conservando due unità per gruppo. La validità del riferimento richiede scambiabilità sotto l’ipotesi nulla o una randomizzazione coerente con il disegno.

R · codice commentato
valori <- c(1, 2, 4, 7)
etichette <- c("A", "A", "B", "B")
nA <- sum(etichette == "A")
nB <- sum(etichette == "B")
contrasto <- function(gruppoA) {
  gruppoB <- setdiff(seq_along(valori), gruppoA)
  mean(valori[gruppoB]) - mean(valori[gruppoA])
}
osservato <- contrasto(which(etichette == "A"))
print(c(nA = nA, nB = nB, contrasto_B_A = osservato))
Risultato dell’esecuzione
nA            nB contrasto_B_A 
            2             2             4

Lettura del risultato

L’uguaglianza delle sole medie non garantisce la scambiabilità quando forma o varianza differiscono. L’esempio assume che le assegnazioni ammesse siano equiprobabili sotto il riferimento nullo.

2. Eseguire e documentare una permutazione

Estraiamo senza reinserimento quali due indici ricevono l’etichetta A. Gli altri diventano B. Non estraiamo nuovi valori e non reinseriamo indici dentro la stessa assegnazione: questo distingue la permutazione dal bootstrap.

R · codice commentato
set.seed(603)
nuovaA <- sample.int(length(valori), nA, replace = FALSE)
nuove_etichette <- rep("B", length(valori))
nuove_etichette[nuovaA] <- "A"
print(data.frame(valore = valori, originale = etichette,
                 permutata = nuove_etichette))
permutato <- contrasto(nuovaA)
print(c(osservato = osservato, singola_permutazione = permutato))
stopifnot(sum(nuove_etichette == "A") == nA)
Risultato dell’esecuzione

Lettura del risultato

Una sola permutazione serve a osservare il meccanismo, non a costruire un p-value informativo. Il valore del contrasto cambia perché cambia l’assegnazione dei valori ai gruppi.

3. Enumerare tutte le assegnazioni

Con quattro unità possiamo elencare tutti i sottoinsiemi di due indici assegnati ad A. Il p-value bilaterale esatto è la quota delle assegnazioni con contrasto almeno altrettanto estremo in valore assoluto, includendo l’assegnazione osservata.

R · codice commentato
assegnazioni <- combn(seq_along(valori), nA)
nulli <- apply(assegnazioni, 2, contrasto)
estremi <- abs(nulli) >= abs(osservato)
p_esatto <- mean(estremi)
print(data.frame(A1 = assegnazioni[1, ], A2 = assegnazioni[2, ],
                 contrasto = nulli, estremo = estremi))
print(c(p_esatto_bilaterale = p_esatto))
stopifnot(isTRUE(all.equal(p_esatto, 2 / 6)))
Risultato dell’esecuzione

Lettura del risultato

La distribuzione è discreta: con sei assegnazioni non si ottiene qualunque p-value. Il conteggio esatto non richiede la correzione usata quando si campiona soltanto un sottoinsieme casuale di permutazioni.

La coda cambia perché cambia l’alternativa, che deve essere formulata prima di osservare il risultato. Non si sceglie la direzione dopo aver visto quale produce il numero minore.

Errore da riconoscere

Non permutare etichette ignorando blocchi o coppie del disegno. Le assegnazioni ammesse devono corrispondere alla scambiabilità o alla randomizzazione effettiva.

Risposta alla domanda

La permutazione costruisce un riferimento mediante riassegnazione delle etichette. Valori, numerosità e statistica rimangono fissi; l’ipotesi che giustifica la riassegnazione va dichiarata.
