Welch: differenza tra medie senza imporre varianze uguali

M06_N06 · Gemina · soluzione eseguita e commentata

Come ricostruiamo il test e l’intervallo di Welch per il contrasto Spiky meno Rounded?

1. Scomporre la varianza del contrasto

Per campioni indipendenti la varianza stimata della differenza è sB²/nB + sA²/nA. Conserviamo separati i contributi dei gruppi. L’indipendenza giustifica l’assenza di un termine di covarianza; l’uguaglianza delle varianze non è necessaria per questa costruzione.

R · codice commentato
dati <- carica_dati("fossili_simulati.csv")
a <- dati$diametro_tot_um[dati$morfotipo == "Rounded"]
b <- dati$diametro_tot_um[dati$morfotipo == "Spiky"]
nA <- length(a)
nB <- length(b)
vA <- var(a) / nA
vB <- var(b) / nB
delta <- mean(b) - mean(a)
se <- sqrt(vA + vB)
print(c(differenza_um = delta, contributo_A = vA, contributo_B = vB, SE_um = se))
Risultato dell’esecuzione

    0.5820284     0.0125113     0.0105688     0.1519214

Lettura del risultato

La somma contiene variabilità di entrambi i gruppi. Welch non corregge dipendenza tra osservazioni, selezione dei campioni o errori nella definizione delle unità.

2. Calcolare statistica, gradi di libertà e intervallo

La formula di Welch-Satterthwaite approssima i gradi di libertà usando i due contributi di varianza. Il risultato può non essere intero e non va arrotondato prima di calcolare probabilità o quantili. La nulla di questo confronto è delta uguale a zero.

R · codice commentato
df <- (vA + vB)^2 / (vA^2 / (nA - 1) + vB^2 / (nB - 1))
delta0 <- 0
t_obs <- (delta - delta0) / se
p <- 2 * pt(-abs(t_obs), df = df)
critico <- qt(0.975, df = df)
intervallo <- delta + c(-1, 1) * critico * se
print(c(t = t_obs, gradi_liberta = df, p_bilaterale = p))
print(c(inferiore_um = intervallo[1], superiore_um = intervallo[2]))
Risultato dell’esecuzione

Lettura del risultato

L’intervallo esprime la differenza nelle unità originali. Il p-value valuta il contrasto rispetto a zero sotto le ipotesi del metodo e non misura la probabilità di un effetto causale.

3. Verificare il verso degli argomenti R

Per ottenere Spiky meno Rounded passiamo b come primo vettore e a come secondo. La verifica di statistica, p-value ed estremi aiuta a intercettare inversioni del segno. Non serve eseguire un test preliminare delle varianze per decidere se usare Welch.

R · codice commentato
automatico <- t.test(b, a, var.equal = FALSE, conf.level = 0.95)
stopifnot(isTRUE(all.equal(unname(automatico$statistic), t_obs)))
stopifnot(isTRUE(all.equal(automatico$p.value, p)))
stopifnot(isTRUE(all.equal(as.numeric(automatico$conf.int), intervallo)))
print(automatico)

Variante svolta

Invertire l’ordine degli argomenti e verificare quali risultati cambiano.

R · codice commentato
invertito <- t.test(a, b, var.equal = FALSE)
print(c(t_originale = t_obs, t_invertito = unname(invertito$statistic)))
print(rbind(Spiky_Rounded = intervallo,
            Rounded_Spiky = as.numeric(invertito$conf.int)))
stopifnot(isTRUE(all.equal(p, invertito$p.value)))
stopifnot(isTRUE(all.equal(as.numeric(invertito$conf.int), -rev(intervallo))))
Risultato dell’esecuzione

    3.83111    -3.83111 
                   [,1]      [,2]

Il test bilaterale mantiene lo stesso p-value, mentre statistica e intervallo cambiano verso. Una conclusione verbale deve seguire il contrasto effettivamente calcolato.

Errore da riconoscere

Non arrotondare i gradi di libertà e non chiamare Welch una soluzione per dati appaiati o raggruppati trattati come indipendenti.

Risposta alla domanda

Welch confronta medie di campioni indipendenti senza imporre varianze uguali. Formula, ordine degli argomenti, unità e limiti del disegno devono essere coerenti.
