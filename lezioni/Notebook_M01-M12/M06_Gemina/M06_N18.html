Come cambia la decisione quando quattro p-value appartengono alla stessa famiglia di domande?

1. Dichiarare la famiglia e ordinare i p-value

La molteplicità riguarda l’insieme delle domande per cui desideriamo controllare almeno un falso rifiuto. Qui la famiglia contiene quattro ipotesi. Ordiniamo i p-value per il calcolo, ma conserviamo i nomi per restituire i risultati alle ipotesi originali.

R · codice commentato
p <- c(H3 = 0.041, H1 = 0.003, H4 = 0.200, H2 = 0.018)
alpha <- 0.05
m <- length(p)
ordine <- order(p)
p_ordinati <- p[ordine]
soglie <- alpha / (m:1)
print(data.frame(ipotesi = names(p_ordinati), p = p_ordinati, soglia_Holm = soglie))
print(c(numero_ipotesi = m, livello_famiglia = alpha))

Lettura del risultato

L’ordine iniziale è volutamente diverso da quello dei p-value. Il controllo dei nomi impedisce di attribuire a un’ipotesi il risultato corretto di un’altra.

2. Applicare la regola sequenziale

Holm confronta il p-value più piccolo con alpha/m e procede solo se il confronto consente il rifiuto. Al primo mancato rifiuto si fermano anche i rifiuti successivi. La funzione cumprod traduce questa regola, senza trattare i confronti come decisioni isolate.

R · codice commentato
supera <- p_ordinati <= soglie
rifiuta_ordinato <- as.logical(cumprod(as.integer(supera)))
aggiustati_ordinati <- pmin(1, cummax((m:1) * p_ordinati))
aggiustati <- numeric(m)
aggiustati[ordine] <- aggiustati_ordinati
names(aggiustati) <- names(p)
print(data.frame(ipotesi = names(p_ordinati), p = p_ordinati,
                 p_Holm = aggiustati_ordinati, rifiuta = rifiuta_ordinato))
stopifnot(isTRUE(all.equal(aggiustati, p.adjust(p, method = "holm"))))
Risultato dell’esecuzione
ipotesi     p p_Holm rifiuta
H1      H1 0.003  0.012    TRUE
H2      H2 0.018  0.054   FALSE
H3      H3 0.041  0.082   FALSE
H4      H4 0.200  0.200   FALSE

Lettura del risultato

Il massimo cumulativo impedisce ai p-value aggiustati di diminuire lungo l’ordine. Il secondo confronto può interrompere la sequenza anche quando un successivo p-value sarebbe inferiore a 0,05 senza correzione.

3. Quantificare il rischio della famiglia in un modello semplice

Se tutti i nulli sono veri e i p-value sono uniformi indipendenti, la probabilità di almeno un p-value sotto alpha è 1−(1−alpha)^m. Simuliamo questo caso e lo confrontiamo con Holm. La formula di indipendenza non va trasferita automaticamente a test correlati.

R · codice commentato
set.seed(618)
B <- 3000
simulati <- replicate(B, runif(m))
errore_grezzo <- mean(apply(simulati, 2, function(z) any(z <= alpha)))
errore_Holm <- mean(apply(simulati, 2, function(z)
  any(p.adjust(z, "holm") <= alpha)))
print(c(FWER_grezzo_teorico = 1 - (1 - alpha)^m,
        FWER_grezzo_simulato = errore_grezzo, FWER_Holm_simulato = errore_Holm))
print(c(MCSE_Holm = sqrt(errore_Holm * (1 - errore_Holm) / B)))
Risultato dell’esecuzione
FWER_grezzo_teorico FWER_grezzo_simulato   FWER_Holm_simulato 
           0.1854938            0.1990000            0.0553333 
 MCSE_Holm 
0.00417419

Lettura del risultato

Holm controlla la probabilità di almeno un falso rifiuto anche con dipendenza fra test, purché i singoli p-value siano validi. La simulazione indipendente mostra un caso, non dimostra tutta la proprietà.

Variante svolta

Confrontare Holm e Bonferroni mantenendo la stessa famiglia e gli stessi nomi.

R · codice commentato
confronto <- data.frame(ipotesi = names(p), p = as.numeric(p),
  Holm = as.numeric(p.adjust(p, "holm")),
  Bonferroni = as.numeric(p.adjust(p, "bonferroni")))
confronto$rifiuta_Holm <- confronto$Holm <= alpha
confronto$rifiuta_Bonferroni <- confronto$Bonferroni <= alpha
print(confronto)
Risultato dell’esecuzione
ipotesi     p  Holm Bonferroni rifiuta_Holm rifiuta_Bonferroni
1      H3 0.041 0.082      0.164        FALSE              FALSE
2      H1 0.003 0.012      0.012         TRUE               TRUE
3      H4 0.200 0.200      0.800        FALSE              FALSE
4      H2 0.018 0.054      0.072        FALSE              FALSE

Le correzioni possono produrre decisioni diverse. La famiglia resta quella dichiarata prima dell’analisi: non si eliminano ipotesi dalla lista dopo aver visto quali risultati sono scomodi.

Errore da riconoscere

Non correggere soltanto i p-value già piccoli o rinominare famiglie a posteriori per ottenere più rifiuti. Documentare quali domande appartengono al controllo comune.

Risposta alla domanda

La correzione multipla richiede una famiglia definita e p-value validi. Holm ordina le evidenze, applica soglie sequenziali e restituisce risultati interpretabili per le ipotesi originali.
