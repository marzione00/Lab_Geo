1. Costruire una nulla sulle medie con varianze diverse

Il modello impone la stessa media ma distribuzioni diverse, perché le deviazioni standard sono differenti. Questo distingue una nulla sulle medie da una nulla che renda scambiabili tutte le osservazioni. Il campione osservato può avere una differenza media non nulla per puro campionamento.

R · codice commentato
set.seed(609)
a <- rnorm(12, mean = 5, sd = 3)
b <- rnorm(40, mean = 5, sd = 1)
osservato <- mean(b) - mean(a)
print(data.frame(gruppo = c("A", "B"), n = c(length(a), length(b)),
  media = c(mean(a), mean(b)), SD = c(sd(a), sd(b))))
print(c(differenza_B_A = osservato))
boxplot(list(A = a, B = b), col = c("#95BDD0", "#E7B977"),
        ylab = "Misura (u.c.)", main = "Medie generatrici uguali, varianze diverse")

       1.53036

Lettura del risultato

L’uguaglianza delle medie generatrici è nota soltanto perché abbiamo costruito i dati. Le etichette non sono scambiabili: conoscere il gruppo informa sulla dispersione del valore.

2. Applicare Welch al contrasto medio

Welch usa separatamente le varianze dei gruppi e approssima i gradi di libertà. L’esempio rende appropriata la distinzione fra varianze, pur restando un singolo campione e non uno studio delle prestazioni del test.

R · codice commentato
welch <- t.test(b, a, var.equal = FALSE)
vA <- var(a) / length(a)
vB <- var(b) / length(b)
se_welch <- sqrt(vA + vB)
print(c(SE_Welch = se_welch, p_Welch = welch$p.value,
        df_Welch = unname(welch$parameter)))
print(welch$conf.int)
Risultato dell’esecuzione
SE_Welch   p_Welch  df_Welch 
 1.082952  0.184409 11.367214 
[1] -0.843842  3.904558
attr(,"conf.level")
[1] 0.95

Lettura del risultato

Il risultato riguarda una differenza fra medie sotto campioni indipendenti. Non dimostra che tutte le caratteristiche delle due distribuzioni siano uguali quando il test non rifiuta.

3. Calcolare la permutazione grezza e dichiararne il limite

Calcoliamo anche la permutazione della differenza non studentizzata per capire che cosa produce. Con varianze diverse e gruppi sbilanciati, la sola uguaglianza delle medie non giustifica questa calibrazione. La tabella deve quindi riportare le ipotesi insieme ai numeri.

R · codice commentato
x <- c(a, b)
B <- 2000
nulli <- replicate(B, {
  i <- sample.int(length(x), length(a), FALSE)
  mean(x[-i]) - mean(x[i])
})
p_perm <- (1 + sum(abs(nulli) >= abs(osservato))) / (B + 1)
confronto <- data.frame(metodo = c("Welch", "Permutazione grezza"),
  p = c(welch$p.value, p_perm),
  riferimento = c("Medie uguali, varianze separate", "Scambiabilita delle etichette"))
print(confronto)
Risultato dell’esecuzione
metodo         p                     riferimento
1               Welch 0.1844090 Medie uguali, varianze separate
2 Permutazione grezza 0.0144928   Scambiabilita delle etichette

Lettura del risultato

La seconda riga è un calcolo illustrativo con riferimento non giustificato dalla sola nulla sulle medie in questo modello. La scelta fra metodi non si fa confrontando quale p-value è minore.

Variante svolta

Rigenerare gruppi con uguale distribuzione sotto la nulla e ripetere i due calcoli.

R · codice commentato
set.seed(1609)
a2 <- rnorm(12, 5, 1)
b2 <- rnorm(40, 5, 1)
x2 <- c(a2, b2)
t2 <- mean(b2) - mean(a2)
nulli2 <- replicate(B, {
  i <- sample.int(length(x2), length(a2), FALSE)
  mean(x2[-i]) - mean(x2[i])
})
print(c(Welch = t.test(b2, a2)$p.value,
  permutazione = (1 + sum(abs(nulli2) >= abs(t2))) / (B + 1)))
Risultato dell’esecuzione
Welch permutazione 
    0.434032     0.483758

Ora la scambiabilità è coerente con il modello generatore. I p-value possono comunque differire per campione finito, metodo di calibrazione ed errore Monte Carlo; non occorre che coincidano.

Errore da riconoscere

Non usare una sola simulazione per dichiarare un test universalmente migliore. Prima confrontare parametro, disegno e nulla, poi eventualmente studiare le prestazioni con repliche controllate.

Risposta alla domanda

Metodi diversi possono rispondere a domande o ipotesi diverse. Un confronto responsabile mette queste differenze davanti al valore numerico del p-value.
