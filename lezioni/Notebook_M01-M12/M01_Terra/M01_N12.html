1. Costruire tre selezioni confrontabili

Manteniamo fissa la popolazione e cambiamo soltanto la regola di selezione. Il campione sistematico usa un inizio casuale fra i primi dieci siti e un passo costante di dieci; quello di convenienza usa i siti iniziali.

R · codice commentato
# Popolazione artificiale finita: la posizione contribuisce al valore.
set.seed(102)
siti <- data.frame(id_sito = sprintf("S%03d", 1:120),
                   distanza_m = seq(0, 1190, by = 10))
siti$valore <- 2.4 + 0.00035 * siti$distanza_m + rnorm(120, 0, 0.04)
media_pop <- mean(siti$valore)

set.seed(103)
n <- 12L
casuale <- sample(seq_len(nrow(siti)), n, replace = FALSE)
inizio <- sample(1:10, 1)
sistematico <- seq(inizio, nrow(siti), by = 10)
convenienza <- seq_len(n)
selezioni <- list(casuale = casuale, sistematico = sistematico,
                  convenienza = convenienza)
stopifnot(all(lengths(selezioni) == n))

Lettura del risultato

La partenza casuale distingue il campionamento sistematico da una scelta fissa della prima posizione. Tutti i metodi rispettano la stessa numerosità, ma non assegnano necessariamente le stesse possibilità di inclusione ai siti.

2. Misurare centro e copertura

Per ogni selezione calcoliamo media, scarto dalla popolazione e distanze estreme. Queste quantità descrivono la singola realizzazione e permettono di collegare uno scarto al tratto effettivamente visitato, senza attribuirlo soltanto alla numerosità.

R · codice commentato
riassunto <- do.call(rbind, lapply(selezioni, function(ind) {
  c(n = length(ind), media = mean(siti$valore[ind]),
    errore = mean(siti$valore[ind]) - media_pop,
    distanza_min_m = min(siti$distanza_m[ind]),
    distanza_max_m = max(siti$distanza_m[ind]))
}))
print(riassunto)
print(media_pop)

Lettura del risultato

Il metodo con errore più piccolo in questa esecuzione non è automaticamente il migliore in generale. Servono ripetizioni e ipotesi sul territorio per confrontare bias e variabilità; una sola estrazione mostra soltanto un esempio.

3. Leggere la selezione nello spazio

Rappresentiamo il medesimo insieme di siti in tre pannelli e sovrapponiamo i punti selezionati. Il confronto visivo rende riconoscibili intervalli regolari, dispersione casuale e concentrazione all’inizio del tratto.

R · codice commentato
vecchio_par <- par(mfrow = c(1, 3))
for (nome in names(selezioni)) {
  ind <- selezioni[[nome]]
  plot(siti$distanza_m, siti$valore, pch = 16, col = "grey75",
       main = nome, xlab = "Distanza (m)", ylab = "Valore (u.c.)")
  points(siti$distanza_m[ind], siti$valore[ind], pch = 19, col = "firebrick")
  abline(h = media_pop, lty = 2)
}
par(vecchio_par)

Lettura del risultato

Il grafico collega la regola di selezione al gradiente presente nella simulazione. Un campione sistematico copre il tratto regolarmente, ma in una popolazione periodica un passo coincidente con il periodo potrebbe fornire una rappresentazione sfavorevole.

Variante svolta

Valutare tutte le dieci partenze possibili del campionamento sistematico.

R · codice commentato
medie_partenze <- vapply(1:10, function(i) {
  mean(siti$valore[seq(i, nrow(siti), by = 10)])
}, numeric(1))
print(data.frame(partenza = 1:10, media = medie_partenze,
                 errore = medie_partenze - media_pop))
stopifnot(abs(mean(medie_partenze) - media_pop) < 1e-12)

Le dieci selezioni hanno uguale numerosità e, insieme, ripartiscono tutti i siti: per questo la media delle loro medie coincide con quella della popolazione. La precisione di una singola partenza rimane una questione distinta.

Errore da riconoscere

Confondere ‘regolare’ con ‘rappresentativo’ trascura la struttura dei valori. Il passo sistematico va valutato rispetto a gradienti e periodicità, e la scelta di convenienza va dichiarata.

Risposta alla domanda

A parità di numerosità, la regola di selezione modifica copertura e risultati. Il confronto dei metodi richiede guardare il disegno oltre alla media ottenuta in un singolo campione.
