1. Racchiudere il procedimento in una funzione

Una funzione con un ingresso esplicito riduce le dipendenze nascoste. Importiamo il file dentro la funzione, controlliamo misure e identificativi, calcoliamo la densità e restituiamo soltanto gli oggetti necessari per leggere il risultato.

R · codice commentato
analizza <- function(file_csv) {
  dati <- read.csv(file_csv, stringsAsFactors = FALSE)
  stopifnot(!anyDuplicated(dati$id), all(is.finite(dati$massa_g)),
            all(dati$massa_g > 0), all(is.finite(dati$volume_cm3)),
            all(dati$volume_cm3 > 0))
  dati$densita_g_cm3 <- dati$massa_g / dati$volume_cm3
  medie <- aggregate(densita_g_cm3 ~ affioramento, dati, mean)
  medie <- medie[order(medie$affioramento), , drop = FALSE]
  list(individuali = dati, medie = medie)
}
file_ingresso <- percorso_dati("campioni_modulo1.csv")
risultato_1 <- analizza(file_ingresso)
print(risultato_1$medie)

Lettura del risultato

dati è un oggetto locale alla funzione: non viene recuperato da una precedente esercitazione. Il nome del file è l’ingresso documentato. Se un requisito non è soddisfatto, il controllo arresta il calcolo prima dell’esportazione.

2. Ripetere a partire dall'ingresso

Chiamiamo di nuovo la funzione e confrontiamo le uscite. Poiché non ci sono estrazioni casuali né dipendenze da oggetti modificati all’esterno, due esecuzioni sullo stesso file devono produrre gli stessi valori e lo stesso ordine.

R · codice commentato
risultato_2 <- analizza(file_ingresso)
stopifnot(identical(risultato_1, risultato_2))
print(c(righe_individuali = nrow(risultato_2$individuali),
        gruppi = nrow(risultato_2$medie)))
identificativi <- risultato_2$individuali$id
stopifnot(length(unique(identificativi)) == 24L)

Lettura del risultato

L’uguaglianza verifica la ripetibilità di questo procedimento deterministico. Non dimostra che la formula scelta risponda a ogni domanda geologica: riproducibilità e validità scientifica sono controlli collegati ma distinti.

3. Verificare anche l'uscita su disco

Salviamo un risultato creato da questa stessa esecuzione e lo rileggiamo. La prova comprende quindi il passaggio dal codice al file consegnabile, senza assumere che una cartella contenga già risultati prodotti altrove.

file_uscita <- percorso_risultati("medie_riproducibili.csv")

verifica <- read.csv(file_uscita, stringsAsFactors = FALSE)
stopifnot(identical(verifica$affioramento, risultato_1$medie$affioramento))
stopifnot(isTRUE(all.equal(verifica$densita_g_cm3,

La modifica di una copia in memoria non cambia il file di partenza né il lavoro locale della funzione. Questo isolamento aiuta a riconoscere analisi che funzionano soltanto perché la sessione contiene oggetti dimenticati.

Errore da riconoscere

Controllare soltanto l’esistenza di file creati da altri notebook non è una prova di autonomia. Il notebook deve ricostruire i propri risultati a partire dagli ingressi dichiarati.

Risposta alla domanda

La procedura è ripetibile perché tutte le dipendenze informative sono esplicite. Per condividerla servono il file originale, il codice e l’ambiente di esecuzione documentato, non una copia della memoria della sessione.
