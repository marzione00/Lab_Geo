## Ambito ed esclusioni

La licenza opera solo sui contenuti originali per i quali l'autore può concedere diritti. **Non modifica le licenze o i diritti dei materiali di terzi**, incluse banche dati, fotografie, mappe, loghi, fonts e testi con attribuzione separata. Consultare i file `PROVENIENZA_DATI.txt`, `FONTI_E_NOTE.txt` e gli altri registri delle fonti disponibili nel progetto.

Per il **software R, Python, JavaScript e per gli script di rendering** non si presume l'applicazione della licenza CC. Le licenze software eventualmente indicate nei rispettivi file prevalgono. Qualora mancasse una licenza software esplicita, non si presume il permesso di redistribuire il codice con licenza CC.
