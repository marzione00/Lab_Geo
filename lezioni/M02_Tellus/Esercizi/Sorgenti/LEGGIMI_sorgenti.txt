TELLUS M02 - SORGENTI DEL QUADERNO STUDENTI

Il generatore legge Quaderno_contenuti_studenti.json, che contiene soltanto
obiettivi, istruzioni, domande e verifiche locali destinati agli studenti.
Le soluzioni del docente non sono incluse.

REQUISITI

- Python 3.10 o successivo.
- Pacchetto Python ReportLab.
- Font Liberation Sans (Regular, Bold, Italic) e DejaVu Sans Mono.
- Fontconfig, con il comando fc-match disponibile: il generatore lo usa
  per individuare i file dei font presenti sul sistema.

Le dipendenze devono essere gia disponibili. Questo progetto non installa
pacchetti o font automaticamente.

RIGENERAZIONE

Aprire il terminale nella cartella Esercizi/Sorgenti/ ed eseguire:

    python genera_quaderno.py --output-dir rigenerato

Il comando scrive nella nuova cartella rigenerato/:

- Tellus_M02_quaderno_esercizi.pdf, composto da 11 pagine A4;
- Esercizi/, con i dieci script R commentati;
- una copia dei contenuti studenti e il riepilogo dei controlli di ingombro.

Per aggiornare il progetto, copiare il PDF e i dieci script R generati
nella cartella Esercizi/. Conservare questi sorgenti in Esercizi/Sorgenti/.
Non occorre modificare i CSV o il file Tellus_laboratori.R.

CONTROLLO VISIVO

Dopo modifiche ai testi, controllare tutte le pagine del nuovo PDF.
Il generatore interrompe la scrittura se una scheda supera lo spazio
disponibile o una riga di codice supera la larghezza del box.

Se Poppler e disponibile, si possono creare immagini di controllo con:

    pdftoppm -r 120 -png rigenerato/Tellus_M02_quaderno_esercizi.pdf pagina

ESECUZIONE DEGLI ESERCIZI IN R

Aprire Tellus_M02.Rproj dalla cartella principale del progetto. Per esempio:

    source("Esercizi/01_progetto.R", encoding = "UTF-8", echo = TRUE)

Ogni script carica Tellus_laboratori.R e poi esegue il confronto descritto
nella scheda. echo = TRUE mostra comandi e risultati nella console.
